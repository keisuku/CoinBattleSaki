# ADR-0007: パチンコ的信頼度エスカレーション演出マッピング設計

## ステータス: 初期案（議論用ドラフト）

## コンテキスト

GDD未解決課題 #2「値動きの大きさ → 信頼度レベル → 演出 の具体的な対応表」。

ADR-0006で勝利演出→ウイニング画面→SNS共有カードのフローは設計済み。
しかし**「勝利に至るまでのリアルタイム演出」**が未定義。

パチンコには「信頼度」という概念がある。保留球の色、リーチの種類、予告演出の組み合わせで
「当たる確率」が段階的に上がり、プレイヤーの脳汁を段階的に引き出す。

CoinBattleSakiでは「値動きの大きさ」が天然の信頼度になる。
値動きが大きいほど「大勝利 or 大損」の確率が上がる。
この天然の信頼度を、パチンコ的な演出エスカレーションに変換するのが本ADRの目的。

### パチンコとの構造的類似点

| | パチンコ | CoinBattleSaki |
|--|---------|----------------|
| 結果の決定 | 抽選で事前決定 | 市場がリアルタイムで決定（未確定） |
| 信頼度の源泉 | 演出の種類・色・組み合わせ | 値動きの大きさ（σ）・出来高・Bot状態 |
| エスカレーション | 予告→リーチ→SPリーチ→激アツ→確定 | 凪→気配→胎動→激突→激アツ→覚醒→臨界 |
| フェイクアウト | リーチ外れ（全体の97%） | 値動きの尻すぼみ（全体の60-70%） |
| 脳汁のピーク | 確定音 + 大当たり | 確定音 + P&Lカウントアップ |

**決定的な違い: パチンコは結果が事前に決まっている。本ゲームはリアルタイム。**
これはパチンコより**本質的にスリリング**。演出が嘘をつく可能性がゼロ。

### パチンコの信頼度設計の参考値（実機データ）

エヴァンゲリオン～未来への咆哮～:
- レバブル前兆予告: 95.6%
- 変動音オフ: 81.7%
- 次回予告: 60.1%
- 押しボタン: 46.8%
- キャラ連続予告: 50.3%

北斗の拳10:
- 練気闘座リーチ: 78.2%（ロゴ落下なら96.9%）
- 保留赤: 55.0%
- 保留七星: 33.7%
- 保留ザコ: 10.6%
- 保留黒: 4.7%

共通パターン: **色の進行（白→青→緑→赤→金→虹）** が全機種共通の信頼度言語。

## Part 1: 8状態変換レイヤーの定義

GDDとADR-0005が参照する「8状態変換レイヤー」の具体的な8状態。

### 設計原則

8状態は以下の3条件を満たす必要がある:
1. Binance APIデータ（価格、出来高、OI、Funding Rate）から導出可能
2. トレーダーでない人でも「体感」できるエンタメ的概念に対応
3. 「何も起きていない」から「完全なカオス」までの全スペクトルをカバー

### 市場8状態（The 8 Market States）

| State | 名前 | 英名 | 市場条件 | 出現頻度 |
|-------|------|------|---------|---------|
| S1 | 凪 (なぎ) | Dead Calm | σ < 0.5、出来高平均以下 | ~60-70% |
| S2 | 気配 (けはい) | Premonition | σ 0.5-1.0、またはBotがポジション取得 | ~15-20% |
| S3 | 胎動 (たいどう) | Quickening | σ 1.0-1.5、方向性が出始める | ~8-10% |
| S4 | 激突 (げきとつ) | Clash | σ 1.5-2.0、明確な方向性、バトル開始 | ~3-5% |
| S5 | 激アツ (げきあつ) | Burning Hot | σ 2.0-2.5、大きなイベント進行中 | ~1-2% |
| S6 | 覚醒 (かくせい) | Awakening | σ 2.5-3.0、極端な動き、覚醒演出 | ~0.5-1% |
| S7 | 臨界 (りんかい) | Critical Mass | σ > 3.0、歴史的イベント | <0.5% |
| S8 | 尻すぼみ (しりすぼみ) | Fizzle | S3以上から反転。フェイクアウト | S3+の60-70% |

### 状態遷移ルール

```
S1 ──(σ上昇)──→ S2 ──(方向性)──→ S3 ──(加速)──→ S4 ──→ S5 ──→ S6 ──→ S7
 ↑                   ↑                |                |      |      |
 └───────────────────┴──(尻すぼみ)── S8 ←──────────────┴──────┴──────┘
```

- **上昇**: 段階的。1ティックで最大2段階スキップ可（突然の暴落時）
- **下降**: S8（尻すぼみ）を経由して即S1へ。エスカレーションはゆっくり、デフレーションは一瞬
- **例外**: ANY → S7（フラッシュクラッシュは即座に臨界へ）
- **S8トリガー**: 直近の動きの50%以上をリトレースした場合

この非対称性が重要: **期待はじわじわ、裏切りは一瞬。パチンコと同じ構造。**

## Part 2: σベースの閾値テーブル

### 計測方法

σ = ローリング48キャンドルのlog returnの標準偏差。Bot時間軸ごとに計算。

| Bot時間軸 | ローリング窓 | キャンドルサイズ | 更新頻度 |
|-----------|-------------|----------------|---------|
| 5m Bot (JOHN/MIKE) | 48本 = 4時間 | 5分足 | 5分ごと |
| 15m Bot (SARAH/EMMA/DELTA) | 48本 = 12時間 | 15分足 | 15分ごと |
| 1h Bot (ALEX/YUKI/ATR) | 48本 = 48時間 | 1時間足 | 1時間ごと |

**なぜ48本**: 安定性と応答性のバランス。レジーム変化（週末の静寂→FOMC後の暴風雨）に適応しつつ、ノイズを排除。

### 各σ閾値の近似BTC %値

| σ閾値 | State | 5m Bot | 15m Bot | 1h Bot |
|-------|-------|--------|---------|--------|
| < 0.5σ | S1: 凪 | < 0.05% | < 0.12% | < 0.3% |
| 0.5-1.0σ | S2: 気配 | 0.05-0.10% | 0.12-0.25% | 0.3-0.6% |
| 1.0-1.5σ | S3: 胎動 | 0.10-0.15% | 0.25-0.37% | 0.6-0.9% |
| 1.5-2.0σ | S4: 激突 | 0.15-0.20% | 0.37-0.50% | 0.9-1.2% |
| 2.0-2.5σ | S5: 激アツ | 0.20-0.25% | 0.50-0.62% | 1.2-1.5% |
| 2.5-3.0σ | S6: 覚醒 | 0.25-0.30% | 0.62-0.75% | 1.5-1.8% |
| > 3.0σ | S7: 臨界 | > 0.30% | > 0.75% | > 1.8% |

**重要**: これらの%値は目安。σベースなので低ボラ期は閾値が自動で縮小し、高ボラ期は拡大する。固定%閾値より本質的に優れている。

### 出来高比率の閾値

| 比率 | 意味 | 効果 |
|------|------|------|
| < 0.7 | 平均以下 | 信頼度を1段階視覚的に減衰（演出が控えめに） |
| 0.7-1.3 | 通常 | 修正なし |
| 1.3-2.0 | やや多い | +5% trust、微かなパルス |
| 2.0-4.0 | 多い | +10% trust、画面パルス |
| > 4.0 | 極端 | +20% trust、画面シェイク |

### S8（尻すぼみ）の検知条件

- S3以上の状態にあること
- 価格がエスカレーションを引き起こした動きの50%以上をリトレース
- リトレースがBot時間軸の2倍以内に発生
- 例: 15m Botで1.5σの上昇（S4）→ 30分以内にその半分以上が戻る → S8

## Part 3: 信頼度 → 演出テーブル

### パチンコの色言語を採用

| State | Base Trust | カラー | パチンコ等価 |
|-------|-----------|--------|------------|
| S1 凪 | 0% | グレー | ハズレ（デフォルト） |
| S2 気配 | 5-15% | 白/青 | 保留変化なし |
| S3 胎動 | 15-30% | 緑 | 保留緑 |
| S4 激突 | 30-55% | 赤 | 保留赤 / リーチ |
| S5 激アツ | 55-75% | 金 | 金保留 / 激アツリーチ |
| S6 覚醒 | 75-90% | 虹/プラチナ | レバブル / 全回転 |
| S7 臨界 | 90%+ | 黒金+雷 | 確変確定 |
| S8 尻すぼみ | N/A | 脱色 | リーチ外れ |

### S1: 凪 — Trust 0%（95%退屈問題の解決策）

| 要素 | 仕様 |
|------|------|
| **背景** | GDD環境: 公園での穏やかな戦い。柔らかい光、雲の動き |
| **キャラ** | アイドルアニメ。JOHNは時計を見る、YUKIは瞑想、SARAHは髪を整える |
| **オーディオ** | アンビエントBGM。静かな市場音（遠いタイピング音、モニターのハム音） |
| **UI** | 価格ティッカーがゆっくり流れる。小さなローソク足チャートが隅に |
| **マイクロイベント** | 30-120秒ごとにBotのアイドル台詞。「...静かだな」「嫌な予感がする」「zzz...」 |
| **テンションランプ** | 10-15分周期のマイクロ緊張サイクル（キャラアニメタイマーで駆動、市場データとは無関係） |

設計根拠: パチンコ台はスピン間も完全にアイドルにならない。サブ画面のミニアニメ、キャラの待機モーション。「アプリを離れると何かを見逃す」感覚を作る。

### S2: 気配 — Trust 5-15%

| 要素 | 仕様 |
|------|------|
| **トリガー** | σ > 0.5 または任意のBotがポジション取得 |
| **背景** | 風が少し出る。葉/紙が画面を横切る。色温度が微かに変化 |
| **キャラ** | 警戒ポーズ。目を細める。手が武器に伸びる |
| **オーディオ** | BGMにサブベースの低音が加わる。シングルping音（低音域） |
| **UI** | 価格表示が微かに拡大。青いシマー効果 |
| **テキスト** | なし（毎回テキストを出すとスパム感。S2は頻繁すぎる） |
| **プッシュ通知** | （アプリ外時）「気配あり... Botが構えています」 |

### S3: 胎動 — Trust 15-30%（パチンコの保留緑）

| 要素 | 仕様 |
|------|------|
| **トリガー** | σ > 1.0 |
| **背景** | 空が暗くなる or 劇的に明るくなる。雲が加速。遠雷 |
| **キャラ** | 戦闘態勢。武器を構える。緑のオーラ。アイドルアニメ停止 |
| **オーディオ** | テンション曲に遷移。心拍のような低音パルス開始（60BPM） |
| **UI** | 価格表示が1.5倍に拡大。緑の枠。ローソク足チャートが画面の30%に |
| **テキスト** | 「動き出した...！」 |
| **予告演出** | キャラ固有の予兆アニメ（2秒）。SARAHの髪が風になびく、JOHNが拳を鳴らす |
| **信頼度インジケーター** | 緑の保留球が隅に出現（パチンコの保留球と同構造） |
| **スタッキング** | 出来高も高い場合（>1.5x）: 予告テキストが黄色にアップグレード |

### S4: 激突 — Trust 30-55%（パチンコのSPリーチ）

| 要素 | 仕様 |
|------|------|
| **トリガー** | σ > 1.5 AND（出来高 > 1.5x OR 複数Botが対立ポジション） |
| **背景** | 完全な環境変化。雷雨/強烈な日差し。「バトルステージ」セット完了 |
| **キャラ** | 対立Bot存在時: 分割画面でユーザーBot vs 最強対立Bot。バトルポーズ |
| **オーディオ** | バトルBGM開始。パーカッション主体。テンポ上昇。大きなローソク足にインパクト音 |
| **UI** | 価格表示2倍・赤色。フルバトルHUD: HPバー（清算までの距離）、P&Lカウンター |
| **テキスト** | 「激突！！」（インパクトフォント、画面フラッシュ） |
| **演出** | 画面が斜めに分割。両Bot対峙。大きなローソク足ごとに負けている側に「ヒット」アニメ |
| **信頼度インジケーター** | 赤の保留球。スタッキング修正があればパルス |

### S5: 激アツ — Trust 55-75%（パチンコの金保留）

| 要素 | 仕様 |
|------|------|
| **トリガー** | σ > 2.0 OR S4 + 複数スタッキング修正で50%超 |
| **背景** | 環境が完全なカオス。炎/電撃エフェクト。ビル揺れ。空が不自然な色に |
| **キャラ** | 特別アニメシーケンス。Bot固有の「本気モード」。アニメのパワーアップ的瞬間 |
| **オーディオ** | 「激アツトラック」— 高エネルギー、聞き間違えない。遷移時に「激アツ確認音」ジングル |
| **UI** | 「激アツ！！」金テキスト、全画面フラッシュ。価格カウンターに炎エフェクト |
| **画面効果** | 金の粒子が画面下から上昇。ビネットエフェクト。バーチャルカメラがゆっくりズームイン |
| **信頼度インジケーター** | 金の保留球、脈動。Trust > 60%なら保留球にヒビが入り光が漏れる |
| **SNSモーメント** | **ここからがスクショ映え圏内。** 画面が十分にドラマチック |

### S6: 覚醒 — Trust 75-90%（パチンコのレバブル級）

| 要素 | 仕様 |
|------|------|
| **トリガー** | σ > 2.5 OR S5 + 継続的モメンタム + Bot大幅含み益/含み損 |
| **背景** | 現実が割れる演出。画面にヒビ。環境が断片化し深層バトル次元が露出 |
| **キャラ** | 覚醒トランスフォーメーション。オーラ/パワーアップ。新フォーム露出 |
| **オーディオ** | クレッシェンド → **1-2秒の完全な沈黙** → ドロップ（エヴァの「沈黙の使い方」を参考） |
| **UI** | P&L数値が画面を支配。利益/損失額が巨大表示 |
| **テキスト** | Bot固有の覚醒台詞。「覚醒せよ...」「これが...本当の力...」 |
| **環境** | 他のBotが観客として出現し反応。「世界」がこの異常事態を認知 |
| **信頼度インジケーター** | 虹/プラチナの保留球。光が溢れ出す |

### S7: 臨界 — Trust 90%+（パチンコの確変確定）

| 要素 | 仕様 |
|------|------|
| **トリガー** | σ > 3.0。月に2-5回レベルのイベント |
| **背景** | 完全な黙示録 / 超越。GDDの「清算カスケード = 地震/火山噴火」を実現 |
| **キャラ** | 必殺技発動。フルアルティメットアタックアニメ。OR KOアニメ（負けている場合） |
| **オーディオ** | **確定音** — このゲームで最も重要な1つの音。「確定 = 勝ちor負けが確定した」を体に刻む |
| **UI** | P&Lカウンターが最終カウントアップモード（スロットのメダル払い出し的演出、ADR-0006接続） |
| **分岐** | 勝利 → ADR-0006の勝利フロー（脳汁→余韻→SNS共有カード）/ 敗北 → KO画面（共有カードなし） |
| **テキスト** | 「必殺！！！」or「清算！！！」方向に応じて |
| **タイムスタンプ** | 「2026.03.09 14:32 JST - BTC -12.4% in 1h」— 歴史的瞬間の記録 |

### S8: 尻すぼみ — フェイクアウト（**最重要の演出設計**）

| 要素 | 仕様 |
|------|------|
| **トリガー** | S3以上から、価格が直近の動きの50%以上をリトレース |
| **背景** | 嵐が唐突に晴れる。反クライマックス的な天気。色が脱色 |
| **キャラ** | **コメディリアクション**。肩すかし。汗マーク。Bot固有のがっかりアニメ |
| **オーディオ** | デフレーションSFX: 「しゅぅぅ...」/ 風船が萎む音。BGMがアンビエントにフェード |
| **UI** | P&Lが固定 → ゆっくり小さい表示に戻る。予告バナーがスライドアウト |
| **テキスト** | Bot固有の台詞。「...なんでもなかった」「フェイクか。次こそは。」「まだ早かったか...」 |
| **持続時間** | 2-3秒のコメディビート → S1へスムーズ遷移 |

**S8が最重要な理由**: プレイヤーはS8を最も頻繁に見る（S3+の60-70%がフェイクアウト）。
これが**フラストレーションではなく笑いになる**かどうかが、ゲーム全体の継続率を決める。

パチンコでもリーチの97%は外れる。でもパチンコユーザーは外れ演出も楽しんでいる。
なぜなら「次こそは」という期待と、キャラのリアクションが面白いから。

## Part 4: シグナルスタッキングシステム

パチンコの「複数予告重なり = 信頼度爆上げ」を市場シグナルで再現。
例: 北斗の拳で「保留赤(55%) + 練気闘座リーチ(78%) + ロゴ落下(96.9%)」→ ほぼ確定。

### スタッキング可能シグナル

| シグナル | ソース | Trust加算 | 視覚インジケーター |
|---------|--------|----------|-----------------|
| **出来高急増** | Volume > 2x 48期平均 | +10-15% | 出来高バー発光、「出来高急増！」テキスト |
| **複数Bot同方向** | 2+ Botが同方向ポジション | +10-15% | 分割画面で複数Bot表示、「共闘！」 |
| **Bot対決** | 順張りBot vs 逆張りBot | +5-10% | 「対決！」バナー、VS画面 |
| **Funding Rate極端** | |FR| > 0.05% | +5-10% | 「市場偏り検知！」インジケーター |
| **OI急増** | OI変化 > 2σ | +10% | 「新規玉急増！」テキスト |
| **連続足** | 3+ ローソク足が同方向 | +5-10% | コンボカウンター出現（「3連！」「4連！」） |

### 計算式

```
effective_trust = base_trust(state) + Σ(applicable_modifiers)
cap at 95%（100%は表示しない — 市場は常に反転しうる）
```

### スタッキング演出例

| 組み合わせ | Effective Trust | 特別演出 |
|-----------|-----------------|---------|
| S3 + 出来高急増 | ~25-40% | 予告テキストが緑→黄色にアップグレード |
| S4 + 複数Bot + 出来高 | ~55-75% | 分割画面バトル、金テキスト、「全Bot一斉出撃！」 |
| S4 + Bot対決 | ~45-60% | VS画面のドラマチック対決アニメ |
| S5 + FR極端 + OI急増 | ~75-90% | 覚醒級演出が前倒しトリガー、「市場崩壊の予兆...」 |

### Bot時間軸クロスのスタッキング

| インタラクション | 意味 | 演出 |
|----------------|------|------|
| 5m Bot AND 15m Bot 同方向 | マルチタイムフレーム確認 | 「時間軸一致！」— 紫オーラ。Trust +15% |
| 5m Bot AND 1h Bot 同方向 | レア — 短期と長期が一致 | 「全時間軸覚醒！」— 虹フレーム。Trust +20% |
| 全順張りBot発動 | 市場が強トレンド | 「トレンド完全形成！」— 同期攻撃アニメ |
| 全逆張りBot発動 | 市場が極端に偏り | 「逆張り総出撃！反転の刻...」— 不吉な赤黒ビジュアル |

ユーザーはこれらのレイヤーを「読む」ことを学ぶ。
「リングが見える AND ゴーストBotが見える AND 地面が割れてる... これは本物だ！」
パチンコプレイヤーが演出の組み合わせを読む力を育てるのと同じ。

## Part 5: 95%退屈問題の解決策

BTC先物の60-70%はS1（凪）。さらに15-20%はS2（気配だがすぐ消える）。
このゲームの全時間の85%以上は「何も起きていない」。

### マイクロイベントシステム（S1状態のエンタメ）

| マイクロイベント | トリガー | 演出 | 持続時間 |
|----------------|---------|------|---------|
| **Botアイドル台詞** | タイマー（60-120秒） | Botがキャラに合った台詞。「...静かだな」「嫌な予感がする」「zzz...」 | 2-3秒吹き出し |
| **市場トリビア** | タイマー（120-300秒） | 「BTC時価総額: $X兆」「現在のFunding Rate: X%」— 教育コンテンツ | 3秒オーバーレイ |
| **Bot同士の会話** | ランダム（2+ Botアイドル時） | JOHN:「動け...」 SARAH:「焦るな、まだ早い」 | 3-5秒ダイアログ |
| **ミニ価格予測** | 5ローソク足ごと | 「次のローソク、上？下？」タップゲーム。連続正解カウンター | 継続中ミニゲーム |
| **歴史フラッシュバック** | ランダム（レア） | 「3日前のこの時間、ここから3σ級の暴落が始まった...」ゴーストチャートオーバーレイ | 5秒 |

### テンションランプ技法

S1内でも10-15分周期で人工的な緊張サイクルを作る:

```
0:00 — 完全な凪（S1ベースライン）
3:00 — Botが横を向く。BGM微変化（マイクロティーズ）
5:00 — 「Hmm...」吹き出し。Botが何かを確認（エンゲージメントパルス）
7:00 — 微かな風。1つのインジケーターが変化（偽りの夜明け）
8:00 — 凪に戻る。Botがリラックス（解決）
10:00 — バリエーションを変えて繰り返し
```

**重要**: これはキャラアニメタイマーで駆動。市場データとは無関係。純粋にコスメティック。
予測的であるとは一切主張しない。

### S2 → S8 サイクルの娯楽価値

S2（気配→消滅）のサイクル自体をエンタメにする:

1. **頻度**: 5m Botなら1時間に8-15回S2がトリガー。ほとんど消える。これは**良い**こと
2. **バリエーション**: 各消滅にBot固有のアニメ（JOHNは空を殴る、MIKEはクールに肩をすくめる）
3. **レア昇格**: S2が実際にS3に進むのは15-30%。フェイクアウトの経験が本物の価値を高める
4. **パブロフの犬**: S2のオーディオキュー（微かなテンション音）がユーザーを画面に向かわせる訓練

## Part 7: 確定音の設計方針

パチスロ文化の確定音（サミー確定音等）はゲーム文化における最も洗練された条件付け装置の一つ。
CoinBattleSakiにもアイコニックな確定音が必要。

### 確定音の要件

1. **200ms以内に認識可能** — 聞いた瞬間に「勝った」と分かる
2. **1000回聞いても不快にならない** — チャイムではなく重みのある音
3. **ドーパミン反応を条件付け** — パブロフの犬。この音 = 脳汁
4. **CoinBattleSaki固有の識別性** — SNS動画で「あの音だ」と分かる
5. **BGM上でも単体でも機能** — レイヤリング可能

### 提案

深い「GONG」に続く結晶的なリング。2パート: インパクト + 残響。
低音の重みと高音の明瞭さが共存する音。

## Part 10: 実装優先度

### Phase 1 MVP: 最小限で演出が成立するセット

| 優先度 | コンポーネント | 理由 |
|--------|-------------|------|
| **P0** | σ計算エンジン（Bot時間軸ごとのローリング標準偏差） | 全状態の基盤。これがないと何も動かない |
| **P0** | S1/S2/S3/S8 演出（アイドル、気配、胎動、尻すぼみ） | ユーザー時間の90%+をカバー。ここが退屈なら即離脱 |
| **P0** | 予告SE + 確定音 | オーディオは体験の50%。パブロフの条件付けの起点 |
| **P0** | S7 → 勝利/KOフロー（ADR-0006接続） | ペイオフの瞬間。ここがないとゲームとして成立しない |
| **P1** | S4/S5/S6 演出（エスカレーション中間） | 重要だが初期はシンプル版でも可 |
| **P1** | シグナルスタッキング（出来高、マルチBot） | 深みを追加。段階的に追加可能 |
| **P1** | 環境システム（背景変化） | 雰囲気を強化。ただしコアではない |
| **P2** | Botアイドル台詞/マイクロイベント | 95%退屈問題の磨き込み |
| **P2** | Bot固有アニメーション（8体分） | 初期は全Botでアニメテンプレート共有可 |
| **P2** | 完全スタッキングマトリクス（FR, OI） | 追加のBinance APIデータが必要 |

### 技術的依存関係

1. **Binance API統合**: OHLCV + 現在価格。理想的にはFunding Rate + OIも
2. **ローリングσ計算**: Bot時間軸ごとに独立した3つの計算窓（5m, 15m, 1h）
3. **状態マシン**: 前進遷移（S1→S7）、尻すぼみ遷移（S3+ → S8）、減衰（S8 → S1）
4. **アニメーションシステム**: レイヤードエフェクト（背景環境 + 前景State演出 + UIオーバーレイ）
5. **キャリブレーション期間**: σが安定するまで48期間必要（5m Bot: ~4時間、1h Bot: ~48時間）。初回起動時はハードコードされた「平均σ」をフォールバック使用
