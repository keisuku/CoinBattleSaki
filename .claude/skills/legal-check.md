# 法務チェック Skill（日本国内向け）

## Description
CoinBattleSakiの機能追加・変更時に、日本の法規制に抵触しないかチェックする。

## Instructions

### 主要な関連法規

#### 1. 金融商品取引法（金商法）
- **投資助言業**: シミュレーション結果が「投資助言」にならないよう注意
  - NG: 「このBotの戦略に従えば利益が出る」
  - OK: 「エンターテイメントとしてのバトルシミュレーション」
- **投資運用業**: ユーザーの実際の資産を運用する機能は絶対に実装しない
- **対策**: 免責事項を必ず表示、シミュレーションであることを明確に

#### 2. 資金決済法
- **前払式支払手段**: ゲーム内通貨が以下に該当すると届出義務
  - 有効期限180日超 + 残高1000円超（自家型）
  - 第三者利用可能（第三者型）→ 登録義務
- **暗号資産交換業**: 実際の暗号資産の売買を仲介する場合は登録必須
  - **本プロジェクトでは実際の暗号資産を扱わないので非該当**
- **対策**: ゲーム内ポイントに有効期限を設ける or 換金性を排除

#### 3. 賭博罪（刑法185条・186条）
- **構成要件**: 「偶然の勝敗」×「財物の得喪」
- **リスクケース**: ランキング報酬で現金相当のものを配布
- **対策**: 報酬はゲーム内アイテム・称号のみ。換金性ゼロ

#### 4. 景品表示法
- **不当表示**: シミュレーション精度を過大に宣伝しない
- **景品規制**: 懸賞の上限額に注意（取引価額の20倍 or 10万円の低い方）
- **対策**: 「バックテスト結果であり将来を保証しない」旨を表示

#### 5. 特定商取引法
- **有料サービス提供時**: 事業者名、住所、電話番号等の表示義務
- **サブスクリプション**: 解約方法の明示義務

#### 6. 個人情報保護法
- **ユーザーデータ**: プライバシーポリシーの整備、利用目的の明示
- **第三者提供**: ユーザーの同意なく第三者にデータ提供しない

### チェックフロー
新機能の実装前に:
1. 上記6法規のそれぞれについて該当性を確認
2. グレーゾーンがあれば「⚠️ 要弁護士相談」フラグを立てる
3. 問題なしなら「✅ 法的リスクなし」として記録
