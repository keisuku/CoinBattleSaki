## 1. 翻訳メソッド: 「流派」としての翻訳

### 翻訳の公式

```
Bot戦略（技術的な取引手法）
  → 市場の急所の突き方（経絡秘孔的 = 戦闘哲学）
    → 流派の体現者（キャラクター）
      → 必殺技体系（市場急所 × キャラ個性）
```

### なぜ「流派」か

北斗神拳が人体の経絡秘孔を突くように、Bot戦略は**市場の急所**を突く。

| 北斗の拳 | CoinBattleSaki |
|---------|----------------|
| 人体の経絡秘孔 | 市場の急所（RSI過熱点、MACDクロス、清算ライン等） |
| 北斗神拳 / 南斗聖拳 / 元斗皇拳 | 順張り流派 / 逆張り流派 / デルタ流派 / ATR流派 |
| 拳法の修行 | Botのパラメータ調整・チャイルドバリアント展開 |
| ケンシロウの孤独な戦い | ユーザーが先物市場に孤軍奮闘で挑む |
| 秘孔を突く → 「お前はもう死んでいる」| 市場急所を突く → エントリー確定 → 利確/清算 |

**これにより「RSI逆張り」が「市場の急所を突く秘拳」に翻訳される。**
暗号資産の知識ゼロでも「こいつは市場の急所を突く拳を持っている」は直感的にわかる。

### 参照元の使い分け

| 参照元 | 何を借りるか | 何を借りないか |
|--------|------------|--------------|
| **北斗の拳（パチンコ）** | 脳汁演出の段階的エスカレーション。経絡秘孔的な必殺技のロジカルな裏付け。確定演出の快感設計 | 筋肉男だけのキャストの偏り。暗すぎるトーン |
| **SF2** | 8体の圧倒的差別化。シルエット/カラー/戦闘スタイルの多様性。30年色褪せない骨格設計 | 格闘ゲームのゲームシステムそのもの |
| **ウマ娘** | ニッチ世界（先物市場）の一般層への翻訳力。推し活×擬人化。キャラの多様な魅力 | 競馬のシステム。全員美少女の均一性 |

## 2. キャストの多様性原則

### 「全員強い。全員違う。」

SF2は春麗もザンギエフもダルシムも同じ画面にいる。
北斗の拳はケンシロウもラオウもマミヤもいる。

**CoinBattleSakiのキャスト原則:**

1. **性別・年齢・体型を統一しない** — おっさんも美少女も老師もいる
2. **統一するのは「圧倒的な強さのオーラ」** — 弱そうなキャラは1人もいない
3. **強さ×セクシー** — 全キャラが「強くて色気がある」。おっさんにも男の色気がある
4. **推し活の多様性** — 「推す理由」が全員違う（かわいい/かっこいい/怖い/美しい/面白い）

### キャスト配分

```
8体のバランス:
  強い男性キャラ    : 2-3体（北斗的・SF2的。おっさん含む）
  強い女性キャラ    : 2-3体（ウマ娘的推し活。ただし戦闘力は男と同格）
  異質・超越的キャラ : 2体（人外感・神秘性。性別を超越した存在感）
```

## 4. 必殺技体系 — 経絡秘孔としての市場急所

### 概念設計

北斗神拳は人体の708の経絡秘孔を突く。
CoinBattleSakiの各流派は**市場の急所（テクニカルシグナル）**を突く。

```
市場の急所（＝経絡秘孔）:
  ├── RSI過熱点（70超/30未満）        → 体の熱暴走/冷却停止
  ├── MACDクロス（GC/DC）             → 気の流れの転換
  ├── ボリンジャーバンド2σ超え       → 体の限界点突破
  ├── 移動平均ゴールデン/デッドクロス → 大きな脈の流れの逆転
  ├── 清算ライン接触                  → 致命的急所（即死点）
  ├── ATR急拡大                       → 体内エネルギーの暴走
  └── ファンディングレート反転         → 陰陽の反転
```

### 必殺技の段階構造（パチンコ演出と連動）

各キャラの必殺技は3段階:

| 段階 | 市場状況 | 演出 | 北斗パチンコで言うと |
|------|---------|------|-------------------|
| **通常技** | 通常のエントリー/イグジット | キャラが技を出す。基本演出 | ザコバトル |
| **奥義** | 大きな利益を伴うトレード | 必殺技名カットイン + 専用演出 | ラオウ登場 |
| **秘奥義** | 清算カスケード級の超大勝利 | フルスクリーン演出 + 確定音 | 無想転生 |

### 「確定演出」の設計 — 脳汁の源泉

北斗の拳パチンコが脳汁マシンである理由:
**「もしかして？→ まさか？→ キタァァァ！！」の段階的エスカレーション**

CoinBattleSakiへの翻訳:

```
Phase 1: 予兆（もしかして？）
  └── 値動きが活発化 → キャラが構えを取る
  └── 演出: 画面の端にオーラが出始める

Phase 2: 接近（まさか？）
  └── テクニカルシグナルが急所に接近
  └── 演出: キャラが技名を呟く / 目が光る / BGMが変化

Phase 3: 突破（来るか...!?）
  └── シグナルが閾値を突破
  └── 演出: 「秘孔に触れた」的カットイン / 画面が震える

Phase 4: 確定（キタァァァ！）
  └── エントリー確定 + 利益方向に動き始める
  └── 演出: 必殺技フル演出 / 確定音 / 利益額カウントアップ開始

Phase 5: 炸裂（脳汁ピーク）
  └── 利確完了。利益額が画面中央にドン
  └── 演出: ウイニングポーズ → SNS共有カード画面へ
```

### 信頼度テーブル（パチンコ的）

| 演出パターン | 信頼度 | 内容 |
|-------------|--------|------|
| キャラが構える | 15% | 値動きあるが大半は不発 |
| 目が光る | 35% | テクニカルシグナル接近 |
| 技名カットイン | 60% | エントリー直前 |
| 画面が割れる | 85% | ほぼ確定。大きな利益の予兆 |
| **確定音 + 金文字** | **100%** | **大勝利確定。脳汁の頂点** |

※ 確率は「大勝利（月間Top成績に貢献するレベルの利益）」に対する信頼度。
  エントリー自体はもっと頻繁に発生する。

## 5. ユーザーの立ち位置 — ケンシロウ的孤独な挑戦者

### ユーザーのメタファー

ユーザーはケンシロウのような存在:
- **孤軍奮闘で先物市場という荒野に挑む**
- 味方は自分が起用するBot（=流派の戦士）だけ
- 市場という巨大な敵に「拳（Bot）」で立ち向かう
- 負けても立ち上がる（翌日10万円リセット）
- 勝ち続ければ伝説になる（ランキング上位 → 「伝説のディーラー」称号）

### 成り上がりの構造

```
地下最下層（養分席）
  ↓ 勝利を重ねる
地下中層（見習い）
  ↓ 安定して勝てるようになる
地下上層（相場読み → 仕手筋）
  ↓ 月間Top成績
地上（相場師）
  ↓ 伝説的成績
天上（伝説のディーラー = VIP）
```

- **地下** = 背徳感。でも笑える。養分仲間とSNSで自虐ネタを共有
- **天上** = セレブ。爆益スクショが映える。称号が誇らしい
- **往復** = 全損して天上から地下に叩き落とされる → 翌日また這い上がる

### 「使いこなし次第で超強いBot」の設計

Botは「与えられた完成品」ではなく、**ユーザーの起用判断で強さが変わる**:

1. **環境読み**: 「今はレンジだからJOHNは休ませてEMMAを出す」
2. **タイミング**: 「雇用統計前だからノーポジにする」
3. **バリアント選択**: 同じJOHNでも _agg(攻撃的) / _con(保守的) を切り替え
4. **連携**: 将来的に複数Bot同時起用で「コンビ技」的な効果

→ Botの素のスペック × ユーザーの判断力 = 総合的な強さ
→ 「このBotは弱い」ではなく「お前の使い方が悪い」（格ゲー的思想）
