# ADR-0008: キャラデザインの翻訳媒介 — 神獣トレーダー

## ステータス: 発展済み → ADR-0010参照

> 本ADRの初期案をADR-0009で分析・改善し、提案Bを選択。ADR-0010で確定版を設計。
> 翻訳媒介の構造（トレーダー × 神獣）・チャイルドバリアント・対立構造・演出接続の基本設計は本ADRが原典。
> キャラクターの性別・名前・神獣種・性格の詳細はADR-0010を参照。

## コンテキスト

GDD最重要未決定事項「キャラデザインの翻訳の媒介 — 何を通じて投資家をバトルキャラにするか」。

### 要件（GDDより）
- SF2のように「先物市場の参加者の頂点」を8キャラに圧縮する
- シルエットだけで誰かわかる
- 色で即座に識別できる
- 戦い方が見た目に直結している
- 全員が全く違う方向性だが、一貫性がある
- 生成AIガチャでは到達不能な深さ

### 制約
- 既存BTCsakimonoの8体マザーBot（JOHN, MIKE, SARAH, EMMA, ALEX, YUKI, DELTA, ATR）の
  **戦略ロジック・時間軸は維持**する
- キャラデザインとして神獣トレーダーの世界観を「被せる」

## 先行事例調査から抽出した5原則

成功IPがどのように「抽象ドメインをバトルキャラに翻訳」したかの調査結果:

| IP | 翻訳元ドメイン | 翻訳の媒介 | なぜ機能するか |
|----|-------------|-----------|-------------|
| SF2 | 世界の格闘技 | 国 × 格闘技 | 国籍が自動的にシルエット・色・動き・性格を全て決定する |
| ウマ娘 | 競馬 | 実在馬の擬人化 | 実在の物語を「感情的にアクセス可能」にした |
| Cells at Work | 人体生物学 | 細胞 = 都市の労働者 | 機能的関係を保ったまま擬人化 |
| Blue Lock | サッカー | 技能 = 名前のついた武器 | **見えないものに名前をつけた**。「空間認識」→「メタビジョン」 |
| ペルソナ5 | 社会への反逆 | 心理的アーキタイプ = 神話的ペルソナ | 心理が戦闘形態を決定。内面の可視化 |

### 5つの必要条件

1. **自動差別化**: 媒介が自動的にキャラ間の差異を生む（デザイナーが無理に差別化しなくていい）
2. **感情的アクセス**: 先物を知らない人でも直感的に理解できる
3. **視覚自明性**: 見た目だけで戦い方が分かる
4. **物語継承**: 既存の物語資源（神話、市場の歴史）を活用できる
5. **機械的対応**: トレード戦略 → 戦闘スタイル → アニメーションが自然に接続する

## 決定: 翻訳の媒介 = 「トレーダー × 神獣（守護霊獣）」

### 構造

```
SF2:    国(日本) × 格闘技(空手) = リュウ
ペルソナ5: 反逆(盗み) × 神話(アルセーヌ) = ジョーカー
本作:   時間軸(5m) × 神獣(隼) × 戦法(順張りスキャルプ) = 白石迅(JOHN)
```

各トレーダーは**神獣（守護霊獣）**を従えている。
神獣は「トレード戦略の具現化」— ペルソナ/スタンドと同構造。

- **トレーダー（人間）** = 感情移入の器。人間ドラマ、表情、台詞、性格
- **神獣（霊獣）** = 戦闘ビジュアルの器。シルエット、色、必殺技、演出の主役
- **両者の関係** = トレーダーの判断が神獣の攻撃として具現化する

### なぜこの媒介が機能するか

1. **自動差別化**: 8体が全て異なる動物（狐/隼/蜘蛛/獅子/牛/白虎/玄武/龍）→ シルエット完全分離
2. **感情的アクセス**: 「速い隼」「力強い獅子」「罠を張る蜘蛛」— 説明不要
3. **視覚自明性**: 神獣の形 = 戦い方。隼は急降下する、蜘蛛は網を張る
4. **物語継承**: 四神（白虎/玄武/龍）＋ 日本神話の狐 → 東洋神話の深み
5. **機械的対応**: 神獣の攻撃パターン = Botの売買パターン。リアルタイムで自然に可視化

### 時間軸 × 神獣のスケール感

短い時間軸 → 小さく速い獣。長い時間軸 → 大きく重い獣。

```
ミリ秒  → 雷狐（雷の速度）
5分     → 隼（急降下の速度）
5分     → 蜘蛛（精密な罠の速度）
15分    → 獅子（突進の力）
15分    → 狂牛（暴力的な力）
1時間   → 白虎（静から動への転換）
1時間   → 玄武（不動の防御力）
全時間軸 → 龍（全てを超越する存在）
```

この「時間軸 = 獣のスケール」は直感的に理解可能で、
ユーザーは「速い戦い方が好きなら小さい獣のBot」「じっくり派なら大きい獣」と自然に選ぶ。

## チャイルドバリアント × 神獣の対応

既存の5バリアント(_agg, _con, _fast, _slow, _risk)は神獣の「形態変化」として表現:

| バリアント | 神獣への翻訳 | 視覚変化 |
|-----------|------------|---------|
| _agg (Aggressive) | **猛形態** — 神獣が攻撃的に変形。角・牙が伸びる、オーラが赤に | より大きく攻撃的なシルエット |
| _con (Conservative) | **護形態** — 神獣が防御的に変形。甲羅・鎧が厚くなる | より堅牢なシルエット |
| _fast (Fast) | **疾形態** — 神獣が流線型に。羽・尾が長くなる | よりスリムで速そう |
| _slow (Slow) | **重形態** — 神獣が巨大化。重厚な存在感 | より大きく重そう |
| _risk (High-Risk) | **狂形態** — 神獣が暴走。制御不能な見た目。エフェクト過剰 | 不安定で危険そう |

**設計意図**: バリアントは「同じ神獣の別形態」であり、新キャラではない。
スキンとしても機能する（課金対象候補）。ユーザーは「猛隼」「護隼」「疾隼」と呼ぶようになる。

## リスク

1. **神獣が8体で足りるか**: 将来Botが追加された場合、新しい神獣が必要。ただし四神の残り（朱雀・青龍）や他の神話的動物の余地は十分にある
2. **デザインの一貫性**: 8種の異なる動物に一貫したアートスタイルを保つのは技術的に挑戦。生成AIでは困難（GDD課題#4）
3. **文化的配慮**: 四神は中国/日本の神話。多国籍キャラ（ホセ、アレクサンドル等）との整合性を検討
4. **バリアント40体の制作コスト**: 8マザー × 5バリアント = 40体。形態変化で対応するが、それでもアセット量は多い
5. **「ペルソナ/ジョジョのパクリ」と見なされるリスク**: 「トレーダー + 守護霊獣」はスタンド/ペルソナに近い。ただし「トレード戦略が具現化したもの」という独自性で差別化可能
