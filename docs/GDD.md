## 0. コンセプト

### ワンライナー
リアルタイムの仮想通貨先物市場データでBotキャラが戦う、
ファンタジースポーツ × パチンコ演出のBot起用バトルゲーム。
Claude Codeで開発された最強Botは、本物の市場で勝てるのか？

### プロダクトの正体
- **ファンタジースポーツ**: ユーザーはBot（選手）を時間帯ごとに起用し、成績で競う
- **ウマ娘**: ニッチな世界（先物市場）をキャラで一般層に届ける
- **パチンコ**: 信頼度段階エスカレーション演出でリアルタイムの値動きを表現
- **リアルデータ**: ゲーム内の全てが本物の市場データで駆動される

### 他サービスとの根本的な違い
- **他（3Commas, Bybit等）**: トレードが前提のツール
- **CoinBattleSaki**: Bot起用判断で競う**ゲーム**。トレード不要

### コア価値
「ゲーム好きだけど暗号資産に触らない人が、ノーリスクで"いかがわしいマネーゲームの世界"を覗き見できるエンターテイメント」
- いかがわしい世界 = 怖いもの見たさの好奇心がフック
- ノーリスク = 自分のお金は1円も動かない
- 暗黙の価値 = 「この通知パターンに慣れたら、本当に先物やる時にも勝てそう」

### メタストーリー
「Claude Codeで最強Botは作れるのか？」
- 開発過程自体がIPの一部
- アプリ内で「CC製」を明示
- SNSで開発過程も配信（アプリへの導線にもなる）

## 2. 世界観

### トーン: ダーク × アンダーグラウンド × 超王道バトル
- SF2初期の「全ジャンル全世界の無差別バトル」の雰囲気
- いかがわしいアンダーグラウンドの世界だが、ねっとりせず爽快
- 清算されても立ち直る。遺恨を残さない

### 環境 = 市場状況
- 雇用統計前後 = 暴風雨の中の戦い
- 平常時 = 公園での穏やかな戦い
- 清算カスケード = 地震/火山噴火
- レンジ相場 = 霧の中の静けさ

### キャラクターの原型
**先物市場の実際の参加者をバトルキャラに翻訳する**:
- ヘッジファンド、オイルマネー、個人投資家、国家権力、取引所

SF2は「世界中の格闘技の頂点」を8キャラに圧縮した。
CoinBattleSakiは「先物市場の参加者の頂点」を8キャラに圧縮する。

> **翻訳の媒介 = 「トレーダー × 神獣（守護霊獣）」** → ADR-0008で初期案設計済み
> - トレーダー（人間）= 感情移入の器
> - 神獣（霊獣）= 戦闘ビジュアルの器（ペルソナ/スタンド型）
> - 構造: SF2の「国 × 格闘技」= 本作の「時間軸 × 神獣 × 戦法」

### キャラデザインの原則（SF2から抽出）
- シルエットだけで誰かわかる
- 色で即座に識別できる
- 戦い方が見た目に直結している
- 全員が全く違う方向性だが、一貫性がある
- 生成AIガチャでは到達不能。深い世界観 → デザイン力 → 画力 → 一貫性の順

## 3. ゲームループ

### ユーザー体験の全体フロー
```
1. Botキャラを知る（見た目 + 戦略特性）
2. 📱プッシュ通知「バトル始まった！！」（突然のエンカウント）
3. スマホを開く（背徳感）
4. 「今のBotでいいか？切り替えるか？ノーポジにするか？」（瞬間判断）
5. パチンコ的演出で推しBotの戦いを観戦（推しBot固定視点）
    → 信頼度段階エスカレーション
    → 尻すぼみ or 大爆発（必殺技/Bot対Botバトル/KO）
6. 成績が累積 → ランキングで他ユーザーと競争
7. SNSでアプリ画面を撮影して投稿（バイラル）
8. 日常に戻る → 1に戻る
```

### キラーフィーチャー: プッシュ通知 = 突然のエンカウント
- Botがポジションを取った瞬間に通知
- 市場は24時間365日 → 通知が来るタイミングが予測不能 → 中毒性と背徳感
- 通知が来たら即座にBot起用判断が求められる
- 実装: ローカル通知（バックグラウンドでBinance API監視 → サーバー不要）

### Bot起用判断
- リアルタイムでいつでも「ノーポジ / BotA / BotB / BotC...」を切り替え可能
- 「雇用統計前だからノーポジにしよう」「今のボラティリティならスキャルBotだ」
- この判断力がランキング上位への鍵

### ランキング
- ユーザー同士の成績ランキング（日次/週次/月次）
- 基盤: GameCenter (Apple) / Google Play Games（サーバー不要）
- ランキング対象 = 「稼いだ額」（元手は関係ない）

## 5. 演出方式: パチンコ的信頼度エスカレーション

> 具体的な演出マッピング（8状態定義・σ閾値・演出テーブル）は ADR-0007 を参照

### 概要
```
値動き発生
  ↓
S1 凪: 何も起きていない → Botアイドルアニメ、マイクロイベント
  ↓
S2 気配: σ > 0.5 → 「何か来るかも？」微かな予兆
  ↓
S3 胎動: σ > 1.0 → 予告演出。緑の保留球。「動き出した...！」
  ↓
S4 激突: σ > 1.5 → バトルモード突入。赤。分割画面でBot対決
  ↓
S5 激アツ: σ > 2.0 → 金の演出。「激アツ！！」スクショ映え圏内
  ↓
S6 覚醒: σ > 2.5 → 覚醒トランスフォーメーション。虹。沈黙→インパクト
  ↓
S7 臨界: σ > 3.0 → 確定音 → 必殺技 → 勝利フロー（ADR-0006）or KO
  ↓
S8 尻すぼみ: S3以上から反転 → コメディ演出で凪に復帰（60-70%の確率）
```

### なぜパチンコ的演出か
- 先物市場の「フェイクアウト（騙し）vs 本物のブレイクアウト」に完全一致
- 95%の退屈な時間問題を解決（S1/S2でもマイクロイベントで「見てしまう」設計）
- パッシブ観戦と完全に合致（パチンコも「見てる」のが主体）
- 「激アツ演出が出た！」をスクリーンレコーディングしてSNS投稿するバイラル構造
- シグナルスタッキング（出来高+複数Bot+FR等）でパチンコの「複数予告重なり」を再現

### SNSバイラルの仕組み
- S5（激アツ）以上がスクショ/画面収録映え圏内
- ユーザーが自発的にアプリ画面を撮影してSNS投稿
- 「アプリの画面自体が撮りたくなるほど面白い」必要がある
- パチンコの激アツ演出をスマホで撮る行動と同じ構造

## 6. キャラクター（Bot）設計

### 設計原則
SF2のキャラデザが30年色褪せない理由:
1. 全世界の格闘技の頂点を、1キャラに圧縮した
2. 深い世界観が先にあって、デザインが生まれた（デザインが先ではない）
3. 8体全部が全く違う方向性なのに、同じ画面に並んでも違和感がない一貫性

### Botの戦い方 = 神獣の個性（ADR-0008）
- スキャルピング型(JOHN/隼) = 手数が多いが浅い攻撃（百裂脚的）
- 逆張りHFT型(MIKE/雷狐) = 鋭いカウンター（バルログ的）
- トレンドフォロー型(SARAH/獅子) = 王道の正面突破（リュウ的）
- ナンピン逆張り型(EMMA/狂牛) = 一撃が重いが読まれると致命的（ザンギエフ的）
- スイング順張り型(ALEX/白虎) = 静から動への転換（ケン的）
- ポジション逆張り型(YUKI/玄武) = 長距離リーチと防御（ダルシム的）
- グリッド/デルタ型(DELTA/蜘蛛) = 面制圧の罠師（ダルシム的）
- ATR全軸型(ATR/天龍) = 全てを超越した最終存在（豪鬼的）

### Bot進化システム
- 負けたBotは修行して新バージョンとして帰ってくる
- マザーBotから門下生が出てくる（リュウ→ケン→豪鬼の構造）
- Botの改良は開発者がClaude Codeで実際に行い、その過程もコンテンツとして公開

### 課金とBotの関係
- **全Botアクセス無料**（Pay to Winなし）
- 課金はスキン/見た目の変更のみ

## 7. アーキテクチャ

> 詳細は ADR-0005 を参照

### Bot内蔵型（ADR-0005で決定）
```
┌─────────────────────────────────────────────────┐
│          CoinBattleSaki（クライアントサイド）       │
│                                                   │
│  ┌──────────┐  ┌──────────┐  ┌──────────────┐    │
│  │ Bot Engine│→│ 8状態変換 │→│ パチンコ的演出 │    │
│  │ (Binance  │  │  レイヤー │  │ + バトル演出  │    │
│  │  API連携) │  │          │  │              │    │
│  └──────────┘  └──────────┘  └──────────────┘    │
│       ↑              ↓              ↓            │
│  Binance API   Bot起用判断     ローカル通知       │
│  (REST)        (ユーザー操作)   (プッシュ通知)     │
│                      ↓                           │
│               GameCenter / Google Play Games      │
│               (ランキング)                        │
│                      ↓                           │
│               localStorage (戦績保存)             │
└─────────────────────────────────────────────────┘
```

- サーバーサイドコード: ゼロ
- ユーザーDB: なし → セキュリティリスク = ゼロ
- 個人情報: 一切保持しない
- ランキング: GameCenter / Google Play Games（サーバー不要）

## 8. マネタイズ

> 詳細は ADR-0004 を参照

### プラットフォーム: App Store / Google Play

### 課金モデル: 完全無料DL + 通知課金 + スキン課金

| 項目 | 価格 | 内容 |
|------|------|------|
| アプリDL | 無料 | 全Bot・全機能アクセス可 |
| プッシュ通知（無料枠） | ¥0 | 1日5回まで |
| プッシュ通知（有料） | ¥1,000/月（将来¥3,000） | 1日30回 |
| 即復活（全損時） | ¥100 | 仮想資金10万円に即復活 |
| キャラスキン | 個別価格 | 見た目のみ変更、性能差なし |

### 通知課金の価値
- 通知なし = アプリを開いて待つだけの時間が長すぎて実質プレイ不能
- 通知あり = 日常生活の中で突然エンカウント（ゲームとして成立）
- ランキング上位勢は全員課金（判断機会が多い = 有利）
- 将来的には「この通知に慣れておけば先物で勝てそう」という深層動機

### 絶対にやらないこと
- ❌ ゲーム内通貨の換金
- ❌ ガチャ
- ❌ 実際の暗号資産を賭けるシステム
- ❌ 投資助言・投資シグナルの提供
- ❌ コピートレード機能
- ❌ 投資成績による成功報酬
