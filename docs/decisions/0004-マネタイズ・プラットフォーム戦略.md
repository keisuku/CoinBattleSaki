# ADR-0004: マネタイズ・プラットフォーム戦略

## ステータス: 承認（v2: 無料DL+通知課金モデルに更新）

## コンテキスト

Phase 0でマネタイズの方向性を定める必要がある。以下の制約条件:
- サーバーコストをゼロまたは極小に抑えたい
- セキュリティリスク（ユーザーDB、個人情報等）を極力排除したい
- 個人開発で運用が破綻しない構造
- 将来的にIPとして成長させたい
- ゲーム好き × 暗号資産未経験者がターゲット

## CoinBattleSakiの本当の価値

**「ノーリスクで本物のマネーゲームの世界を覗き見でき、Bot起用判断で競うゲーム」**

- 他サービス（3Commas, Bybit等）はトレードが前提のツール
- CoinBattleSakiはBot起用判断で競う**ゲーム**。トレード不要
- 暗黙の口コミ: 「これやってると勝てるらしい」
- アプリ自体は投資助言・取引機能を一切持たない

## 決定: 完全無料DL + 通知課金 + スキン課金

### 旧モデル（却下）
¥3,000 or ¥1,490 買い切り → DLの壁が高い

### 新モデル（採用）
無料DL → 全機能使える → 通知が足りない → 課金

### 課金構造

| 項目 | 価格 | 内容 | 課金動機 |
|------|------|------|---------|
| アプリDL | 無料 | 全Bot・全機能アクセス | - |
| プッシュ通知（無料枠） | ¥0 | 1日5回まで | - |
| プッシュ通知（有料） | ¥1,000/月 | 1日30回 | ゲームとして成立するために実質必須 |
| プッシュ通知（将来） | ¥3,000/月 | 上位プラン | 需要に応じて値上げ |
| 即復活（全損時） | ¥100 | 仮想資金10万円に即復活 | 翌日待てない |
| キャラスキン | 個別価格 | 見た目のみ変更 | 推しの着せ替え |

### なぜ無料DLに変更したか
1. **DLの壁がゼロ** → SNSで見たら即DL → バイラル加速
2. **通知の価値が自明** → 通知なし=待ち時間が長すぎてゲームにならない
3. **Pay to Winではない** → 通知は「判断機会の増加」であり「勝率の保証」ではない
4. **サーバーゼロ維持** → Apple/Googleのサブスク管理に委任

### 通知課金が機能する理由
- 無料5回 → 「あのバトル見逃した…」が発生
- 課金30回 → ほぼ全てのBot起用チャンスに反応可能
- ランキング上位勢は全員課金（判断機会が多い = 有利）
- 表層動機: 「待ち時間長すぎ。通知ないと無理」
- 深層動機: 「この通知に慣れたら先物で勝てそう」

### アーキテクチャ（サーバーゼロ）

```
Binance API（市場データ）
      │
      ▼
[Bot Engine + 演出 + ローカル通知]  ←── 全部入りクライアントサイド
      │
      ├── iOS App（無料DL + アプリ内課金）
      └── Android App（無料DL + アプリ内課金）
```

- サーバーサイドコード: ゼロ
- ユーザーDB: なし
- 認証: Apple ID / Google ID（プラットフォーム依存）
- 個人情報: 一切保持しない
- プッシュ通知: ローカル通知（バックグラウンドAPI監視）
- ランキング: GameCenter / Google Play Games
- セキュリティリスク: 事実上ゼロ

### Apple Store審査対策

CoinBattleSakiは「ゲーム」として申請:
- カテゴリ: ゲーム > シミュレーション
- 実取引機能なし、ウォレット連携なし、入出金機能なし
- 課金はスキンと通知機能のみ（トレード機能ではない）
- Apple Guideline 3.1.5(b)対策: 「エンターテイメントシミュレーション」を強調

## 法的注意事項

1. **投資助言業**: 投資助言機能は一切ない。Bot起用はゲーム内の仮想資金のみ
2. **免責事項**: アプリ内に「投資助言ではない」を常時表示
3. **景品表示法**: 過去実績の表示は注記付き。将来の収益保証は禁止
4. **成功報酬**: 成功報酬モデルは採用しない
5. **課金対象**: 通知頻度とスキンのみ。投資成績に連動した課金は一切行わない

ゲームとして設計されており、実際の金銭・暗号資産の移動は一切発生しない。
仮想資金はゲーム内ポイントであり換金不可。

## 収益シミュレーション

### 最小ケース
- DAU 500人 × 課金率10% × ¥1,000/月 = ¥50,000/月
- 復活課金: DAU 500 × 月2回全損 × ¥100 × 50%利用 = ¥50,000/月
- Apple税30%後 = ¥70,000/月
- サーバー費 = ¥0

### 成長ケース
- DAU 5,000人 × 課金率15% × ¥1,000/月 = ¥750,000/月
- 復活 + スキン: ¥250,000/月
- Apple税30%後 = ¥700,000/月
- サーバー費 = ¥0

## リスク

1. **Apple審査リジェクト**: 暗号資産関連として厳しく見られる
   → 対策: 「ゲーム」として申請。取引機能一切なし。通知とスキンのみ課金
2. **通知の価値が伝わらない**: 無料5回で十分と思われる
   → 対策: ゲームループの設計で通知の価値を自明にする
3. **Binance API依存**: API停止でゲーム停止
   → 対策: 将来的に複数取引所対応
4. **大手の参入**: 上位互換を出される
   → 対策: キワモノ領域で大手は手を出しにくい。先行者利益+IP構築

## 代替案
- 買い切り¥1,490-3,000: DLの壁が高いため却下
- Webのみ（Stripe課金）: サーバーが必要になるため却下
- 完全無料+広告: 個人開発では広告収益が小さすぎる
- NFT/トークン: 法的リスクが高すぎるため却下
