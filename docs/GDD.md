## 1. コンセプト

### ワンライナー
仮想通貨先物市場のトレーディングBotのパフォーマンスを、
エンターテイメントとして視覚化・擬人化するアプリ。

### エレベーターピッチ
> 「仮想通貨市場で24時間戦い続けるBotたちを擬人化。
> リアルタイムの市場データが、キャラクターの感情や行動に変換される。
> 見るだけで市場の空気感がわかる、新感覚のトレーディングエンターテイメント。」

> ⚠️ **注意**: 「格闘ゲーム」とは限定しない。
> 演出方式はPhase 0で検証の上決定する。

### 未決定事項（Phase 0で必ず決める）
1. **演出方式**: 格闘ゲーム？レース？ダンス？事後演出動画？固定パターン？
2. **コアエモーション**: ユーザーに持って帰ってもらう感情は？
3. **トーン**: 熱血？クール？ポップ？シュール？
4. **ターゲット**: トレーダー向け？一般向け？
5. **コンテンツ形態**: アプリ？SNS動画？配信コンテンツ？

## 2. 「そもそも何が面白いのか？」の検証（最優先）

### 検証すべき仮説

#### 仮説1: 「Bot同士のパフォーマンス比較」自体に興奮がある
- 検証方法: 過去データで2つのBot戦略の成績をスプレッドシートで比較し、
  10人に見せて「面白い？また見たい？」と聞く
- コスト: ¥0、半日
- 判定基準: 10人中7人以上が「面白い」

#### 仮説2: 「擬人化」すると面白さが増す
- 検証方法: 同じ戦績データを「数値表」と「キャラ付き表示」の2パターンで見せて比較
- コスト: 画像生成AI代のみ、1日
- 判定基準: キャラ付きの方が「また見たい」の割合が有意に高い

#### 仮説3: 「リアルタイム」であることが重要
- 検証方法: 過去データの事後レビューとリアルタイム配信、どちらが盛り上がるか
- コスト: ¥0、1日（過去データで擬似リアルタイム配信）
- 判定基準: リアルタイムの方がSNS反応が多い

#### 仮説4: 最適な演出方式は何か
- 検証方法: 5つの方式でモックアップ/動画を作り、反応を比較
- コスト: 動画生成AI代のみ、3日
- 判定基準: 最もSNSでシェア/いいねされた方式

> **鉄則**: 仮説が検証されるまでコードは書かない

## 3. 演出方式の選択肢（未決定）

### A: リアルタイムゲームエンジン方式（格闘ゲーム/レース等）
```
市場データ → ゲームエンジン(Phaser等) → リアルタイム描画
```
- 開発: 3-6ヶ月（ゲームエンジン経験なしの場合）
- メリット: 没入感が最も高い。「プレイしている」感覚
- デメリット: 開発コスト最大。95%の時間は横ばい相場で退屈になるリスク

### B: 固定演出パターン + 動画生成AI方式
```
市場データ → 状態判定（エントリー/強気/弱気/様子見等） → 対応する固定演出動画を再生
```
- 開発: 1-2週間（動画選択ロジックのみ）
- メリット: 動画AIで高品質な演出を大量生産可能。開発は超軽量
- デメリット: パターンが有限。同じ動画が繰り返される
- **具体的な演出パターン案**:
  - エントリー狙い中: キャラが構えを取る / 目を光らせる
  - 超強気ポジション（ハイレバ）: 技を繰り出す / 吠える / オーラを纏う
  - 様子見: 腕組み / 瞑想 / 相手を観察
  - 自信100%級: 必殺技モーション / 指を鳴らす / 不敵な笑み
  - 損切り: よろめく / 膝をつく / 歯を食いしばる
  - 清算（KO）: 吹き飛ぶ / 画面暗転 / リタイア演出

### C: テキスト実況 + 静止画キャラ方式
```
市場データ → 実況テキスト自動生成 + キャラ表情差分表示
```
- 開発: 1週間
- メリット: 最軽量。キャラの表情差分5枚+テキストだけで成立
- デメリット: 地味。視覚的インパクトが弱い

### D: チャートオーバーレイ方式
```
価格チャート上にキャラの状態アイコン/表情を重ねて表示
```
- 開発: 1-2週間
- メリット: 実用性が高い。TradingView拡張的な価値
- デメリット: 「ゲーム」ではなく「ツール」。IP展開しにくい

### E: ショート動画/SNSコンテンツ自動生成方式
```
1日の戦績 → ハイライト抽出 → 30秒動画を自動生成 → SNS投稿
```
- 開発: 2-4週間
- メリット: バイラル可能性最大。TikTok/YouTube Shorts向け
- デメリット: 「アプリ」ではなく「メディア」。リアルタイム性なし

### F: ハイブリッド方式
```
通常時: C（テキスト+静止画）
ドラマ発生時（清算カスケード等）: B（動画演出）発動
日次: E（ハイライト動画）を自動投稿
```
- 開発: 2-3週間（段階的）
- メリット: メリハリがある。コスト効率が良い
- デメリット: 複数方式の管理が必要

## 6. マネタイズ戦略（Phase 3以降）

> ⚠️ マネタイズの実装前に必ず法務チェック（legal-check skill）を実行すること

### 候補（安全度順）
1. **広告**: バナー広告、動画間インタースティシャル（最も安全）
2. **サブスクリプション**: 月額制でプレミアム機能解放（特商法対応必要）
3. **キャラクタースキン販売**: 外見のみ変更、性能差なし（比較的安全）
4. **投げ銭**: ライブ観戦時の投げ銭（資金決済法の確認必要）

### 絶対にやらないこと
- ❌ ゲーム内通貨の換金
- ❌ ガチャ（確率表示義務＋社会的リスクが高い）
- ❌ 実際の暗号資産を賭けるシステム
- ❌ 投資助言・投資シグナルの提供
