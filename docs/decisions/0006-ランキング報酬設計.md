# ADR-0006: ランキング報酬設計

## ステータス: 提案（議論中）

## コンテキスト

GDD未解決課題 #3「勝った先の報酬」。

ランキング上位に何を用意するか。ユーザーがBot起用判断を磨き、
ランキングで上位に入った時に「報われた」と感じる仕組みが必要。

### 制約条件（絶対に破れないもの）
1. **サーバーゼロ**: GameCenter / Google Play Gamesで完結
2. **換金不可**: ゲーム内の何も現金と交換できない
3. **Pay to Winなし**: 報酬が「勝率の保証」になってはならない
4. **投資助言の禁止**: 報酬が投資シグナルになってはならない
5. **法的リスク回避**: 景品表示法、賭博罪に抵触しない
6. **個人開発で運用破綻しない**: 物理的な景品発送等は不可

### なぜ報酬設計が重要か
- ランキングがあっても「だから何？」では継続しない
- パチンコの出玉 = 景品交換所がある。本ゲームにはそれがない
- ファンタジースポーツには賞金がある。本ゲームには賞金がない
- **「勝つこと自体が楽しい」だけで回るか？** が核心の問い

---

## 分析: 先行事例の報酬構造

### 1. 成功F2Pゲームの報酬設計（調査結果）

| 事例 | 報酬 | 実態 | 学び |
|------|------|------|------|
| ツムツム | 友達間ランキング1位 = 3,000コイン（ガチャ0.1回分） | **報酬は口実。友達に勝つ快感が本体** | LINEという日常ツールにランキングが埋め込まれている構造が10年継続の理由 |
| ウマ娘 | チャンミ: 限定称号 + ジュエル | **初回「1位だけ称号」→不満続出→全員に薄く配る設計に変更** | 1位だけ報酬は不満を生む。幅広い層に称号を配るのが正解 |
| パズドラ | ランダン王冠（効果なし。公式に「ただの飾り」） | **効果がないからこそ純粋な実力の証として渇望される** | 効果をつけるとPay to Win批判。効果なし = 最も価値ある報酬 |
| モンスト | チーム勲章 + 称号（Top3のみ） | チーム解散で勲章消滅 → チーム継続のインセンティブ | マルチプレイの一体感が動機 |
| Clash Royale | リーグ昇格報酬 + Hall of Fame（Top1000）+ 限定バッジ | Golden Step（降格防止）で「萎え離脱」を防止 | 階段を登る達成感 + 名誉のみで回る |
| 将棋ウォーズ | 段位・称号 | 実力の証明 | 純粋な実力証明で継続する層は確実に存在する |

### 2. 心理学的根拠: なぜ「名誉だけ」で回るのか

| 理論 | 内容 | 本ゲームへの適用 |
|------|------|-----------------|
| **自己決定理論（有能感）** | 人間は「自分は有能だ」と感じたい根源的欲求がある | 称号 = 「先物で勝てる判断力」の可視化 |
| **社会的比較理論** | 人は他者と比べて自分の価値を判断する | ランキング = 常に比較対象が存在 → 動機が消えない |
| **Crowding Out効果** | 外発的報酬（景品）が強すぎると内発的動機（楽しいからやる）が死ぬ | **報酬を厚くしすぎると「景品のためにやっている」になり、景品がなくなった途端に離脱する** |
| **純粋性の逆説** | 効果がないバッジほど「純粋な実力の証」として渇望される（パズドラ王冠現象） | 機能報酬をつけない方が報酬の価値が上がる |

### 3. 本ゲームが取れる道
- リアル報酬（賞金） → **不可**（賭博規制・投資助言リスク）
- ゲーム内機能報酬（資金ボーナス等） → **不採用**（Crowding Out効果 + Pay to Win批判リスク）
- 社会的証明（称号・バッジ・SNS共有） → **採用**（成功F2Pゲームの共通パターン）

## 決定: 名誉特化の報酬設計（1層集中）

### 設計方針

**「報酬を薄くすること」が正解である。**

先行事例調査とゲーミフィケーション心理学の知見から、
成功F2Pゲームのランキング報酬は**意図的に薄い**。

- パズドラ: 王冠は「効果なし」。それが最も渇望される報酬
- ウマ娘: 称号を薄く広く配る設計に収束
- ツムツム: 3,000コイン（ほぼ無意味）。友達に勝つ快感が本体

**機能報酬（仮想資金ボーナス・通知枠ボーナス等）は不採用。**
理由:
1. Crowding Out効果: 外発的報酬が内発的動機を殺す
2. Pay to Win批判リスク: 「上位者がさらに有利」は離脱の原因
3. 純粋性の毀損: 効果をつけると称号の「実力証明」としての価値が下がる
4. 実装・バランス調整コスト: 個人開発で維持困難

### 報酬一覧: 社会的証明（承認欲求）に全振り

**「俺は先物の世界で勝てる人間だ」という自己認識の獲得**

これがCoinBattleSaki独自の最大報酬。他のゲームでは得られない。

| 報酬 | 内容 | 実装 |
|------|------|------|
| **ランク称号** | 月次成績で段位付与（「鬼殺し」「相場師」「伝説のディーラー」等） | ローカル保存 + GameCenter表示名 |
| **累積戦績** | 通算勝率・最高記録・連勝記録がプロフィールに刻まれる | ローカル保存 |
| **SNS共有カード** | 成績をOGP画像として生成し、X/Instagram等に投稿可能 | クライアントサイド画像生成 |
| **ランキング順位バッジ** | 「月間Top10」「週間1位」等のバッジがプロフィールに永久表示 | ローカル保存 |
| **限定スキン** | 課金では買えない限定キャラスキン（**効果なし**） | ローカル保存 |

なぜこれが効くか:
- 「先物で勝てる判断力がある」は、ゲーム外でも社会的価値を持つ
- X等で戦績を共有 → 「すごい」「教えて」と反応がある → 承認欲求が満たされる
- パチンコの「出玉報告」と同じ構造（パチンコの出玉もSNSで報告する層が存在する）
- バイラル効果: 成績共有 = アプリの宣伝 = 新規ユーザー獲得
- 限定スキン = 「課金では手に入らない = 効果なし = 純粋な実力の証」（パズドラ王冠と同じ構造）

#### ランク称号の段階設計（案）

```
月次成績ベース（仮想資金10万円スタート）:

  損失（マイナス）    → ランクなし
  ¥0〜¥50,000       → 見習い
  ¥50,001〜¥200,000  → 相場読み
  ¥200,001〜¥500,000 → 仕手筋
  ¥500,001〜¥1,000,000 → 相場師
  ¥1,000,001以上      → 伝説のディーラー

  特殊称号（条件付き）:
  - 「不敗」: 月間の全損ゼロ
  - 「鬼殺し」: 暴落相場で月間プラス
  - 「千里眼」: 月間Top10を3ヶ月連続
  - 「神の手」: 月間1位
```

#### ウマ娘の教訓: 称号は幅広く配る

ウマ娘チャンミで「1位だけ称号」→不満続出→緩和の流れがあった。
本ゲームでも**全プレイヤーが何かしらの称号を得られる設計**が必要:
- 月次成績ベースの称号 → マイナスでなければ全員に付与
- 特殊称号 → 「不敗」等は上位でなくても条件達成で獲得可能
- バッジ → 「初月間完走」「通算100戦」等の参加系も用意

### 将来施策: メタ報酬（コミュニティ・IP）— Phase 2以降

| 報酬 | 内容 | 実装時期 |
|------|------|---------|
| **殿堂入り** | 歴代月間チャンプがアプリ内に永久掲載 | Phase 2以降 |
| **Bot命名権** | 新Botの名前を月間1位が提案できる | Phase 2以降 |
| **開発参加権** | 月間Top10が次のBot戦略の方向性に投票できる | Phase 3以降 |

設計意図:
- Phase 1では社会的証明層のみで運用
- コミュニティが成長したらメタ報酬を追加
- 「Bot命名権」はコスト0で強い動機づけ（自分の名前がゲームに残る）
- リアルグッズは削除（個人開発で運用破綻リスク）
- 運営コスト最小でインパクト最大を追求

## 核心の問い: 「勝つこと自体が楽しい」で回るか？

### 回答: 回る。ただし条件付き。

CoinBattleSakiが「勝つだけで楽しい」ゲームになる条件:

1. **勝ちの実感が派手であること**
   - パチンコ的演出が必須。地味な数字の増加だけでは回らない
   - 「やったぁぁぁ！」と声が出る瞬間が必要 → 演出設計の課題と直結

2. **勝ちを人に見せられること**
   - SNS共有カードの質が極めて重要
   - 「この画面を見せたらすごいと思われる」デザインが必要
   - スクショ映えするUI = バイラルの起点

3. **勝ちの記録が残ること**
   - 累積戦績が消えない。自分の成長が可視化される
   - 「半年前は見習いだったのに今は相場師だ」

4. **負けが致命的でないこと**
   - 翌日10万円リセットは既にこれを実現している
   - 清算されても「まぁ明日もらえるし」→ 気軽に再挑戦

### パチンコとの比較

| | パチンコ | CoinBattleSaki |
|--|---------|----------------|
| 中毒性の源泉 | 演出 + 出玉（金銭） | 演出 + ランキング + 承認 |
| 金銭報酬 | あり（景品交換所） | なし |
| 承認報酬 | 弱い（SNS投稿する層は少数） | 強い（SNS共有が設計に組み込まれている） |
| 復帰コスト | 高い（実費） | ほぼゼロ（翌日無料リセット or ¥100） |

**結論: 金銭報酬の欠如を「承認報酬の強化」で補う設計。**

## 不正対策

サーバーゼロ = 不正検知が困難。以下で対策:

### ローカル改ざんリスク
- ランキングデータがGameCenter/Google Play Games依存
- GameCenter/Google Play Gamesは端末署名ベースなので完全な改ざんは困難
- ただし脱獄端末等での改ざんリスクは残る

### 対策方針
1. **「稼いだ額」のスコア送信時に妥当性チェック**
   - Binance APIの実データと照合（ローカルで）
   - 理論上ありえない利益額は弾く
2. **異常検知**
   - 月間利益が理論上限を超えるスコアを非表示にする閾値設定
   - 例: 100倍レバ × 全額 × 最大ボラティリティでも到達不能な額は弾く
3. **Phase 2以降**: コミュニティ通報 + 手動BAN（サーバー必要）

### 割り切り
- Phase 1ではローカル妥当性チェックのみ
- 少数の不正者よりゲーム体験の質を優先
- 「不正して1位取っても金銭的見返りがない」のが最大の抑止力

## リスク

1. **「報酬がショボい」と思われる**
   → 対策: SNS共有カードの映えを極限まで高める。パズドラの王冠が証明するように「効果なし＝ショボい」ではない
2. **不正でランキングが崩壊する**
   → 対策: Phase 1は閾値チェックのみ。金銭報酬がないので不正動機が弱い
3. **ランキング上位が固定化する**
   → 対策: 日次/週次ランキングで新規参入の余地を残す。月次は実力者向け
4. **下位プレイヤーが「何も得られない」と感じる**
   → 対策: 参加系バッジ + 成績ベース称号（マイナスでなければ全員に付与）でウマ娘の教訓を反映

## 代替案（検討の上、却下）

1. **暗号資産を報酬にする** → 賭博罪リスク。法的に不可
2. **Amazon/iTunes ギフト券** → サーバー必要 + 運営コスト + 景品表示法
3. **報酬なし（ランキングのみ）** → 継続動機が弱すぎる
4. **NFTバッジ** → 法的リスク + ターゲット層（暗号資産未経験者）に合わない
5. **広告報酬（動画広告を見ると復活）** → UX劣化。世界観と合わない
6. **ゲーム内機能報酬（仮想資金ボーナス・通知枠ボーナス）** → Crowding Out効果で内発的動機を殺す。Pay to Win批判リスク。先行事例調査で「効果なし報酬」の方が成功することが判明
