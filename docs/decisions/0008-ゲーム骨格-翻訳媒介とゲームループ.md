# ADR-0008: ゲーム骨格 — 翻訳媒介とゲームループの確定

## ステータス: 承認

## コンテキスト

PROJECT-STATUS.mdでU-01「キャラデザインの翻訳媒介（投資家→バトルキャラの変換方法）」が
「プロジェクト全体の骨格であり、最重要未決定事項」と明記されていた。

翻訳媒介の決定には、ゲームループ全体の構造が不可分であるため、
本ADRでは翻訳媒介とゲームループの骨格を一体として定義する。

### 解くべき問い

> Botの数値的特性（5分足トレンドフォロー、1時間足平均回帰…）を、
> プレイヤーが「別の生き物」と感じるレベルのキャラクター個性にどう変換するか？

### 制約条件
- ADR-0005: Bot内蔵型・サーバーゼロアーキテクチャ
- ADR-0004: 無料DL + 通知課金¥1,000/月
- GDD v0.5: パチンコ演出方式（信頼度積み上げ型）
- CLAUDE.md: SF2原則（少数精鋭・最小操作×最大表現・根本的差別化・即座のフィードバック・骨格の強さ）
- 個人開発 + AI：製作工数を最小限に抑える必要がある

---

## 決定

### 1. 翻訳媒介：金の世界のアーキタイプ蒸留方式

**SF2がやったこと（実在の格闘家→アーキタイプに蒸留）を、金の世界で行う。**

| SF2の前例 | 元ネタ | 蒸留結果 |
|-----------|--------|---------|
| リュウ | 大山倍達（極真空手） | 「求道者」 |
| ザンギエフ | ロシアのレスラー | 「巨大な力」 |
| ダルシム | インドのヨガ行者 | 「異質な間合い」 |

**CoinBattleSakiで同じことをやる：**

| 元ネタの空気感 | 蒸留方向 |
|--------------|---------|
| プロップファーム・朝倉未来的 | ストリートハスラー（成り上がり） |
| ポーカー王 | カジノの魔術師（一瞬を撃つ） |
| ヘッジファンドマネージャー | ウォール街の支配者 |
| 闇金ウシジマくん的 | 冷徹な回収者 |
| アラブ石油王・ソブリンウェルス | 悠然たる王族 |
| 日銀介入オペレーター | 沈黙の巨砲 |
| ゴールドマン・サックス的 | データの暗殺者 |
| 伝説の老練トレーダー | 嵐を待つ者 |

**原則：**
- 実在の人物を直接使わない（肖像権・炎上リスクゼロ）
- 金融世界の普遍的アーキタイプに蒸留する（30年後も通用する永続性）
- 「そういう人たちの世界を覗いてみたかった！」という覗き見欲求を満たす
- 人間×非人間（幻獣等）の混在はOK（牙狼方式）

### トーン
- **ダーク・大人向け**
- 参照作品：北斗の拳パチンコ、牙狼（GARO）、闇金ウシジマくん
- キーワード：金の匂い、裏の世界、覗き見欲求

### 2. ゲームループ：軍師方式（作戦→観戦）

プレイヤーは「軍師」。バトル前に作戦を立て、バトル中はリアルタイムで演出を観戦する。

```
【作戦フェーズ】プレイヤーが決める4要素
  ├─ エース選抜（ロスターから1体を選ぶ。SF2のキャラ選択と同じ）
  ├─ 通貨ペア選択（BTC/ETH/SOL等。通貨によってBotの得手不得手が変化）
  ├─ レバレッジ設定（リスク×リターンのトレードオフ）
  └─ 資金投入額（給料のうちいくら賭けるか。温存 or 全賭けの判断）
         ↓
【エンジンフェーズ】エースがリアルタイム市場データで自動トレード
  └─ Binance REST APIポーリング（ADR-0005準拠）
         ↓
【演出フェーズ】リアルタイムで北斗/牙狼的バトル演出
  ├─ 小利確 → 雑魚蹴散らし演出
  ├─ 大ポジション → 強敵バトル演出
  ├─ 清算カスケード → ボス戦・必殺技演出
  ├─ 損失 → ダメージ・ピンチ演出
  └─ 勝利確定後 → 余韻演出（スキップ可）
```

#### エース1体制（SF2方式）

バトルに投入するのは**エース1体のみ**。SF2でキャラを1人選ぶのと同じ構造。

- 「このBot × この通貨 × このレバで行くか？」の判断が全て
- スタミナ制度により各Botの1日の出撃回数に制限
- 「今この市場にこのBotを投入するか、夜のBTC暴落に温存するか？」
- シンプルだが深い。SF2原則2「最小操作×最大表現」の体現

### 3. Bot階層構造：ロスター→デプロイ→演出

```
【ロスター（手持ち）】全Botの一覧
  ├─ 8体のマザーアーキタイプ（フル演出資産）
  │   └─ 各マザーに派生バリアント（初期はスキン差分、戦略パラメータ違い）
  ├─ 人気の派生 → 独立キャラに昇格（段階的にフル演出資産を追加）
  └─ メジャーアップデートで新アーキタイプ追加
         ↓
【デプロイ（出撃）】エース1体を選ぶ
  └─ スタミナ制度で1日の出撃回数に制限
         ↓
【演出（バトル）】エース = ケンシロウ
  └─ 雑魚→強敵→ボスの流れで1人で戦う
```

#### 派生バリアントの段階的昇格

| 段階 | 状態 | 演出資産 | 例 |
|------|------|---------|-----|
| Lv.0 | スキン差分 | マザーと共有（色・アクセサリー変更のみ） | ハスラー(攻撃的) = 赤いハスラー |
| Lv.1 | 準独立 | マザーの演出 + 固有ポーズ・セリフ追加 | ハスラー(攻撃的) → 固有の勝利ポーズ |
| Lv.2 | 完全独立 | フル演出資産（新キャラとして独立） | ハスラー(攻撃的) → 「狂犬」（新キャラ） |

**昇格基準**: プレイヤーの使用率・人気度に基づき開発者が判断。
工数を段階的にかけられるため、無駄な演出投資を回避できる。

#### 拡張ロードマップ

| フェーズ | ロスター |
|---------|---------|
| MVP | 8体のマザーアーキタイプ |
| v1.x | 各マザーにスキン差分バリアント追加 |
| v2.x | 人気バリアントの独立キャラ昇格 |
| v3.x+ | 新アーキタイプ追加（シーズン制） |

### 3. 勝敗と進行システム

**勝敗基準：P&L + 実績称号**
- メイン指標：仮想ポートフォリオの損益（P&L）
- サブ指標：実績称号（連勝、最大利益、生存日数等でアンロック）

**資金モデル：給料制 + スタミナ**
- 毎日ログインボーナスで「給料」を支給
- スタミナ制度：各Botの1日の出撃回数に制限あり
- 課金でスタミナ回復が可能
- 「今回いくら賭けるか」の判断 = 給料の温存戦略
- 現実の資金運用に近い感覚を目指す

**バトル時間：最短3〜5分**
- 演出は超ライト（即終了）〜フル演出まで段階的
- 利益幅・利益額に応じて演出の豪華さが変化

### 4. 演出の時間軸

- **リアルタイムストリーム**: 市場イベント発生時に即座に演出が走る
- **ハイライト再生**: バトル後、最も印象的な場面を1本再生可能
  - 無料：1本
  - 課金：最大3本
- 「帰りの電車で今日のバトルを振り返る」体験

## 理由

### なぜ「金の世界のアーキタイプ蒸留」か

1. **覗き見欲求**: 「ヘッジファンド」「石油王」「闇金の世界」を覗きたいという
   普遍的な欲求に応える。幻獣やロボットではこの欲求を満たせない
2. **SF2の成功法則の踏襲**: SF2が格闘技の世界でやったことを金の世界で行う。
   実在の人物→アーキタイプへの蒸留で永続性と個性を両立
3. **キャラの立ちやすさ**: 「石油王」「ストリートハスラー」は
   シルエットだけで伝わるレベルの個性を持つ（SF2原則1: 少数精鋭）
4. **法的安全性**: 実在の人物を直接参照しないため肖像権問題なし

### なぜ「軍師方式」か

1. **パチンコ演出との親和性**: 「作戦を立てて、結果を見守る」は
   パチンコの「台を選んで、演出を見守る」と同じ構造
2. **北斗の拳/牙狼パチンコの快楽**: 「来るか？来るか？」の緊張と
   「キター！」の解放。介入できないからこそ演出に集中できる
3. **作戦立案の深さ**: Bot編成×通貨ペア×レバレッジ×資金配分で
   十分な戦略性がある（SF2原則2: 最小操作×最大表現）
4. **工数効率**: バトル中のインタラクションを実装しないで済む

### なぜ「P&L + 実績称号」か

1. P&Lは最もシンプルで直感的な勝敗指標
2. 称号は長期的なモチベーション（名誉特化、ADR-0006と整合）
3. 総合スコアは分かりにくくなるリスクがある

### なぜ「給料制 + スタミナ」か

1. 毎日ログインする動機（デイリーアクティブユーザー維持）
2. 現実の「月給で投資する」感覚に近い
3. スタミナが課金ポイントになる（ADR-0004のマネタイズと整合）
4. 破産リセットのストレスを軽減しつつ、資金管理の緊張感は維持

---

## リスク

| リスク | 影響 | 対策 |
|--------|------|------|
| 「金の世界のアーキタイプ」が陳腐に見える | キャラが安っぽくなる | CDS（ADR-0007）で品質ゲートを設け、安っぽいキャラを排除 |
| 軍師方式だとバトル中の暇が生まれる | 離脱率上昇 | 演出のテンポ設計で解決（パチンコが証明済み） |
| スタミナ制度がユーザーにストレスを与える | 課金圧が強すぎると低評価 | 無料でも1日数回は遊べるバランス設計 |
| 覗き見欲求が投資助言と混同される | 法的リスク | ADR-0004の法的安全設計を厳守。「これはゲームです」の明示 |

## 代替案

### A. 格闘技/武道スタイル方式
ボクシング=スキャルピング、柔道=平均回帰、空手=トレンドフォローのように
格闘技と戦略をマッピング。SF2の原点回帰だが「金の匂い」がしない。却下。

### B. 時間感覚=人生哲学方式
5分足=刹那主義者、1時間足=哲学者のように時間軸を性格にマッピング。
詩的で美しいが、キャラの立ちが弱く「チープになりやすい」という懸念。却下。

### C. 幻獣/モンスター方式
Botを幻獣やモンスターとして表現。ビジュアルは映えるが
「金の世界を覗きたい」という核心的欲求を満たせない。
ただし牙狼方式で**敵キャラや混在要素として**活用することは可能。部分採用。

### D. 実在の人物を直接モデルにする方式
朝倉未来、イーロン・マスク、林社長等を直接モデルに。
キャラは最も立つが、肖像権問題・炎上リスク・時事性による賞味期限切れが致命的。却下。

### E. 雇用→観戦型（パチンコ純粋型）
作戦フェーズなしでBot選択のみ。工数最小だが戦略性が薄い。
軍師方式の方がファンタジースポーツ的深みがある。却下。

### F. 雇用→介入型（監督方式）
バトル中にブースト・撤退等の介入が可能。ゲーム性は高いが
パチンコ演出の「見守る快楽」を阻害し、工数も大幅増加。却下。

## 補足

### 8体のマザーBotの仮名について

ADR-0005で定義された仮名（JOHN, MIKE, SARAH等）は技術的な識別子であり、
最終的なキャラクター名とは別物である。

キャラクターの具体的なデザイン・名前・ストーリーは、
本ADRで決定したアーキタイプ蒸留方式に基づき、別途CDS（ADR-0007）で定義する。

### ADR-0005「48体」との関係

ADR-0005では「8マザー×5バリアント=48体」と定義したが、
本ADRではBot階層構造を以下のように再定義した：

- **8マザーアーキタイプ**: フル演出資産を持つ独立キャラ（ADR-0005を継承）
- **バリアント**: 戦略パラメータが異なるがスキン差分で演出資産を共有（初期状態）
- **昇格バリアント**: 人気に応じて独立キャラへ段階的に昇格

48体が一度に独立キャラとして必要なわけではない。
MVPでは8体のフル演出資産 + バリアントはスキン差分のみで開始し、
段階的に拡張する。
