# 設計課題 #5: 信頼度エスカレーション演出の設計

> **ステータス**: Phase 0 - 構想・設計段階
> **最終更新**: 2026-03-10
> **バージョン**: 0.1.0

---

## 0. この文書の目的

CoinBattleSakiの演出の核心 ——「いつ・何が・なぜ画面に起きるか」を定義する。
パチンコの信頼度エスカレーション構造を参考にしつつ、
**リアルタイムに結果が変わる先物市場ならではの演出**を設計する。

---

## 1. パチンコとの根本的な違い

| | パチンコ | CoinBattleSaki |
|---|---------|---------------|
| 結果の決まり方 | 演出の前に内部で確定済み | リアルタイムに変わり続ける |
| 演出の役割 | 確定済みの結果を装飾する | **Botの「今の気持ち」を映す** |
| 面白さの源泉 | 「当たるかも？」の期待感 | 「攻撃が不発→仕切り直し→再挑戦」の本物のドラマ |

先物市場では、いい感じに上がっても途中で戻されることが日常（7〜8割はそうなる）。
これが「攻撃が空振りして仕切り直し」という演出として自然に機能する。
パチンコの「ハズレリーチ」に似ているが、CoinBattleSakiでは**本当にリアルタイムで起きている**。

---

## 2. 画面の5つの状態

### 全体フロー

```
【通常】→【気配】→【カットイン】→【バトル】→【ラッシュ or 決着】
```

### 2.1 通常時

- **画面**: 背景だけが流れている。キャラは画面にいない
- **背景例**: 公園、観光地など穏やかな風景
- **情報**: 30秒おきにシグナルの状況を小さく表示する程度
- **音**: 環境音のみ

パチンコと同じで、**何も起きていない時間はキャラすら出さない**。
何もない時は本当に何もない。だからこそ何か起きた時に映える。

### 2.2 気配

背景が変わるトリガー = **Bot達の緊張度の総和**。

| 状況 | 背景の変化 |
|------|----------|
| 選択中のBotがシグナルを検知した | 穏やか → やや不穏（荒野、風が出る） |
| 他のBotもざわつき始めている | さらに不穏に（強風、変なアイテムが出る） |
| 複数Botが同時にエントリー気配を出している | 嵐の予兆（暗雲、稲妻の気配） |

背景の変化は「市場データそのもの」ではなく「**Botが何かを感じ取っているかどうか**」で決まる。
1体だけがざわつくなら少し不穏。複数体が同時なら「何か大きいことが起きる」と伝わる。

演出アイテムの例:
- 画面上部や中央の**役物が動く**
- 画面端に予告的なアイテムが出現
- 色味がじわっと変化する

### 2.3 カットイン

Botがポジションを取る瞬間の演出。

```
1. 目をつぶったキャラがカットインで登場
2. 目を開ける → 「近いかも！？」
3. 構えのポーズ → バトル開始
```

ここで初めてキャラが画面に現れる。
通常時にキャラがいないからこそ、この登場に重みがある。

### 2.4 バトル

**演出の激しさ = 利益額の進捗率で決まる。**

Botがポジションを取った瞬間に「利確ライン（勝ちの金額）」と「損切りライン（負けの金額）」が決まっている。現在の損益がそのどちら寄りかで、演出が段階的に変わる。

#### 勝ちに向かう時

| 進捗（利確ラインに対して） | Botの気持ち | 画面の様子 |
|---|---|---|
| 0〜10% | 「まだわからない」 | 構えたまま、小さな動き |
| 10〜30% | 「動き始めた」 | 攻撃の予備動作 |
| 30〜50% | 「読み通りだ」 | 攻撃モーション開始 |
| 50〜70% | 「これは獲れる！」 | 画面が揺れる、エフェクト激化 |
| 70〜80% | 「あと少し…！」 | 必殺技チャージ中 |

#### 負けに向かう時

| 進捗（損切りラインに対して） | Botの気持ち | 画面の様子 |
|---|---|---|
| 0〜-20% | 「想定内」 | 変化なし |
| -20〜-50% | 「ちょっとまずい」 | 画面が暗く冷たくなる |
| -50〜-80% | 「やばい…」 | 被ダメージ演出、画面が歪む |
| -80〜-100% | 瀕死 | 画面暗転、大ダメージ |

#### 攻撃不発 → 仕切り直し

進捗率が一度50%以上まで行ったのに、戻された場合:

```
12:00  エントリー         → 構える
12:02  進捗+50%          → 攻撃モーション開始！
12:03  進捗+60%          → 必殺技チャージ中！
12:04  ★進捗+30%に戻る   → 攻撃が空振り！相手が回避！
12:05  進捗+10%に戻る     → 仕切り直し。間合いを取り直す
12:06  再び進捗+40%      → もう一度攻撃態勢に
12:08  進捗+100%         → 今度こそヒット！勝利！
```

逆パターン（追い詰められてからの巻き返し）:

```
12:00  エントリー         → 構える
12:15  進捗-75%          → 大ダメージ、瀕死
12:30  進捗-90%          → 画面暗転、もうダメか…
12:45  ★進捗-50%に回復   → 「まだ終わってない…」起き上がる
13:00  進捗+40%          → 逆転攻撃！
13:15  進捗+100%         → 劇的逆転勝利！
```

### 2.5 ラッシュモード

**利確設定の8割に到達したら突入。**

```
エントリー ──────────────────→ 利確ライン
0%              80%（ラッシュ突入）   100%
                  ↓
[通常バトル] → [敵を一旦倒す] → [ラッシュモード]
```

- 8割到達で一旦敵を倒す演出が入る
- 残り2割は「応援モード」— 利益がどこまで伸びるかを見守る
- 金色のキラキラ演出、利益カウンターが回る
- じっくり型Botの方が利幅が大きいので、キラキラが派手になる

### 2.6 決着

| 結果 | 演出 |
|------|------|
| 利確（勝ち） | 勝利ポーズ、利益額ドーン表示 |
| 損切り（負け） | KO演出、損失額表示 |
| 清算（大負け） | 特別KO演出（地震/崩壊的） |

## 3. Bot別の演出の違い

演出の激しさ自体は利益額で統一的に決まるが、**Botの個性は攻撃モーションやテンポで出す**。

### 速攻型（JOHN, MIKE — 5分足）

- **攻撃**: 素早い連打（百裂脚的）
- **テンポ**: 1日10〜20回バトル。1回が短い
- **勝率**: 高め（55%）だが1回の利益は小さい
- **特徴**: サクサク回る。地味な勝ち負けが多く、たまに激アツ

### じっくり型（SARAH, ALEX — 15分〜1時間足）

- **攻撃**: 長い溜め → ドカンと一発（ザンギエフ的）
- **テンポ**: 1日1〜3回。1回が長い
- **勝率**: 低め（40%）だが勝つ時の利益が大きい
- **特徴**: ラッシュモードに入りやすい（利幅が大きいので金キラキラが多い）

### 逆張り型（EMMA, YUKI, ATR）

- **攻撃**: カウンター（みんなが怖がっている時に逆に入る）
- **テンポ**: 状況次第
- **特徴**: 他のBotがピンチの場面で登場する。成功すれば嵐の中で涼しい顔

### 影の型（DELTA）

- **攻撃**: 潜伏 → 確信した時だけ動く
- **テンポ**: 攻撃頻度は低いが精度が高い
- **特徴**: 普段は静かだが、動いた時は「本気だ」とわかる

## 4. 演出パターンの出現率（参考）

実際の先物市場のデータ傾向に基づく、各パターンの出現頻度の目安。

### 速攻型の場合

| パターン | 割合 | 内容 |
|---------|------|------|
| あっさり勝ち | 25% | 盛り上がらずに利確 |
| そこそこ盛り上がって勝ち | 20% | 中程度の演出で勝利 |
| 攻撃不発→仕切り直し→勝ち | 10% | 一度空振りしてからの勝利 |
| あっさり負け | 20% | 静かに撤退 |
| 盛り上がったのにハズレ | 15% | 激アツまで行ったのに負け |
| 追い詰められてKO | 5% | ズルズル負ける |
| 劇的逆転勝利 | 3% | 瀕死からの大逆転（激レア） |
| 大暴落/大暴騰に巻き込まれる | 2% | 清算の波（超激レア） |

### じっくり型の場合

- 「攻撃不発→仕切り直し」が多い（騙しの動きが多い時間軸）
- 勝率は低いが、勝つ時は演出がド派手（ラッシュモード突入率が高い）
- 大暴落/大暴騰がトレンドを加速して大勝ちor大負けになる展開が5%程度

## 5. 環境演出との関係

背景は「Bot達の緊張度の総和」で変わるが、市場全体の大きなイベントも影響する。

| 市場の状態 | 環境演出 |
|----------|---------|
| 平常時 | 公園、観光地（穏やか） |
| Bot1体がざわつく | 荒野、風が出る |
| 複数Botがざわつく | 強風、予告アイテム出現 |
| 重要指標の前（雇用統計等） | 暗雲、嵐の予兆 |
| 大暴落/大暴騰 | 地震、火山噴火 |
| 動きがない膠着状態 | 霧、静けさ |

---

## 6. まとめ — 演出設計の3原則

> **原則1: 何もない時は本当に何もない**
> 背景だけ。キャラなし。だからこそ何か起きた時に映える。

> **原則2: 演出の激しさ = 利益額の進捗率**
> Bot種別に関係なく、利確/損切りラインへの進捗で統一的に決まる。

> **原則3: 攻撃不発 → 仕切り直しが日常**
> 先物市場の7〜8割はフェイクアウト。これが演出の主役。
