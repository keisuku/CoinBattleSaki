# ADR-0001: 実データ連動シミュレーション方式の採用

## ステータス: 承認

## コンテキスト
CoinBattleSakiの通貨モデルとして、以下の3つの選択肢がある：
1. 完全シミュレーション（架空データ）
2. 実データ連動シミュレーション（実際の市場データを使うが取引は仮想）
3. 実際の暗号資産を使用

## 決定
**実データ連動シミュレーション**を採用する。

## 理由
- リアルな市場データを使うことで「今まさに起きている戦い」という臨場感が生まれる
- 実際の暗号資産を扱わないため、金商法・資金決済法の規制対象外となる可能性が高い
- 賭博罪のリスクも排除できる（実際の財物の得喪がない）
- 将来的にBotを実運用に転換したいユーザーへのステップとしても機能する

## リスク
- 取引所APIの利用規約に違反しないか確認が必要
- 市場データの商用利用可否をAPI提供元に確認すべき
- 「シミュレーション結果 ≠ 投資助言」の免責を徹底する必要がある
- リアルタイムデータの遅延やAPIダウン時の対応が必要

## 代替案
- **完全架空データ**: リアル感がなくなり差別化が弱い。法的リスクは最小
- **実際の暗号資産使用**: 金商法（暗号資産交換業の登録）が必要。個人開発では非現実的
