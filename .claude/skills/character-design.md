# キャラクターデザイン Skill

## Description
BTCsakimonoで稼働中のBot戦略をキャラクターに擬人化する際の設計ガイド。
トレーディング戦略の特性→キャラクター性格・外見・表現への変換ルール。

> **前提**: Botは既にBTCsakimonoで動いている。
> ここで行うのは「既存Botの戦略的特徴をキャラクターIPに翻訳する」作業。

## Instructions

### Bot戦略→キャラクター変換フレームワーク

#### ステップ1: BTCsakimonoの既存Bot戦略を分析
対象のトレーディング戦略を以下の軸で分析:
- **速度**: 超短期（スキャルピング）〜 長期（スイング）
- **リスク許容度**: ハイリスクハイリターン 〜 保守的
- **手法**: テクニカル / ファンダメンタル / 裁定取引 / AI予測
- **使用指標**: RSI, MACD, ボリンジャーバンド, 出来高, etc.

#### ステップ2: キャラクター属性マッピング
| 戦略特性 | キャラクター属性 |
|---------|----------------|
| スキャルピング | 素早い・短気・連続攻撃型 |
| スイングトレード | 落ち着き・力溜め型・一撃必殺 |
| ハイリスク | 攻撃力高・防御力低・ワイルド |
| 保守的 | 防御重視・カウンター型 |
| テクニカル重視 | 計算高い・メガネ・知性派 |
| AI/ML系 | サイバー・未来的・予測能力 |
| 裁定取引 | 分身・瞬間移動・二刀流 |

#### ステップ3: 格闘ゲームとしての技設計
- **通常技**: 基本的な売買行動に対応
- **必殺技**: 戦略のコア指標がトリガー条件を満たした時の特殊行動
- **超必殺技**: 大きな市場変動時のバーストアクション
- **防御技**: ストップロス、ヘッジ等の防御行動

#### ステップ4: 一貫性チェック
- [ ] 戦略の特性とキャラクターの性格が矛盾しないか
- [ ] 技のモーションが戦略の動きを直感的に表現しているか
- [ ] 他のキャラクターとの差別化ができているか
- [ ] IPとして魅力的で、グッズ化・アニメ化した時に映えるか
