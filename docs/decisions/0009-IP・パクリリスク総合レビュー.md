## 目的

CoinBattleSaki の全設計要素について、以下の観点からIP侵害・パクリリスクを徹底レビューする:

1. 著作権侵害リスク（表現の類似性）
2. 商標権リスク（名称・タイトルの類似性）
3. 特許権リスク（ゲームメカニクス・システム）
4. 不正競争防止法リスク（混同惹起・著名表示冒用）
5. パチンコ的演出の法的位置づけ
6. 金融規制リスク（再確認）

## 1. 法的大原則 — 「アイデア」vs「表現」の二分論

日本の著作権法における最重要原則:

| 保護されない（アイデア） | 保護される（表現） |
|---|---|
| ゲームのルール・システム | 具体的なキャラクターデザイン・イラスト |
| ジャンル・コンセプト | 独自性のある画面構成・演出 |
| 機能的なUI配置 | 具体的なシナリオ・テキスト |
| ゲームメカニクス全般 | 特徴的で独自性のあるUI表現 |
| ありふれた表現 | 創作的な組み合わせ・構成 |

**判例根拠**:
- 最高裁平成13年「江差追分事件」: アイデアと表現の二分論を確立
- 知財高裁平成24年「釣りゲーム事件」: ゲームルール・操作方法はアイデアの領域
- 東京地裁令和3年「放置少女事件」: スマホゲームの著作物性は「特に特徴的であり独自性があると認められるような限定的な場合」のみ

## 2. タイトル「CoinBattleSaki」のリスク分析

### 2.1 「咲-Saki-」（小林立・スクエニ）との混同リスク

| 項目 | 詳細 |
|---|---|
| **リスクレベル** | ⚠️ 中〜低 |
| **類似点** | 「Saki/サキ」という名称 |
| **相違点** | ジャンル完全別（麻雀 vs 仮想通貨Bot）、タイトル構成が異なる |
| **商標状況** | 「咲-Saki-」はスクウェア・エニックスが商標登録済の可能性が高い |

**判断**: 「Saki」は日本の一般的な人名（咲、紗季、早紀など）であり、それ自体に独占権は認められにくい。ただし:
- ゲームカテゴリ（第9類・第41類）で「Saki」単体が商標登録されている場合はリスクあり
- 「CoinBattleSaki」は全体として十分に識別力があり、「咲-Saki-」との混同可能性は低い
- キャラクター名として「サキ」を前面に出す場合は、ビジュアルが麻雀少女と類似しないよう注意

**推奨アクション**:
- [ ] J-PlatPat（特許庁）で「Saki」「サキ」の第9類（ゲームソフト）・第41類（ゲーム提供）商標登録を確認
- [ ] タイトルに「サキ」を含むゲームの既存商標を網羅的に検索
- [ ] リスク回避のため「Saki」がキャラクター名なのかゲーム概念なのか明確化

### 2.2 「CoinBattle」部分

| 項目 | 詳細 |
|---|---|
| **リスクレベル** | 🟢 低 |
| **理由** | 一般的な英単語の組み合わせ。記述的（descriptive）であり商標としての識別力が弱い |

**類似タイトル検索すべきもの**:
- 「Coin Battle」を含むゲームアプリ
- 「コインバトル」表記のゲーム

## 3. パチンコ的演出のパクリライン — 最重要セクション

### 3.1 結論: パチンコ演出は「業界共通文法」であり、パクリにならない

パチンコ業界の演出は、以下の理由から著作権の「アイデア」側に分類される:

#### なぜパチンコ演出は著作権で保護されにくいのか

| 理由 | 説明 |
|---|---|
| **機能的表現** | リーチ・信頼度・確変などは遊技機の「機能」であり、その表現方法は機能的制約を受ける |
| **業界標準化** | 複数メーカー（SANKYO、Sammy、NEWGIN、平和、京楽など）が同じ演出文法を共有 |
| **遊技機規則による制約** | 風営法・遊技機規則により演出パターンが制約されており、表現の選択幅が狭い |
| **歴史的蓄積** | 30年以上の業界慣行で確立された共通言語 |

#### パチンコ演出の「アイデア」と「表現」の境界

| アイデア（自由に使える） | 表現（パクリになりうる） |
|---|---|
| リーチ演出という概念自体 | 特定機種の具体的な映像・アニメーション |
| 信頼度という概念（低→中→高→激アツ→確定） | 特定機種固有のカットイン画像・構図 |
| 確変（連続当たり）の仕組み | 特定キャラクターを使った演出シーケンス |
| 図柄回転→停止の演出パターン | 特定の楽曲・SE |
| 予告演出の段階的エスカレーション | 特定機種の背景美術・UIデザイン |
| ボタン演出（プレイヤーインタラクション） | 他社キャラのパロディ・模倣 |
| 全回転・プレミアム演出という概念 | 特定機種のプレミアム演出の映像そのもの |
| テンパイ→ハズレ/当たりの緊張構造 | — |
| ラッシュモード（連荘）の概念 | — |

### 3.2 CoinBattleSaki が安全に採用できるパチンコ要素

GDD/ADR-0008で定義された「信頼度エスカレーション演出」は以下の構造:

```
Phase 0 (静寂) → Phase 1 (兆し) → Phase 2 (緊張) → Phase 3 (開戦) → Phase 4 (激闘) → Phase 5 (決着)
```

**判定: ✅ 安全**

理由:
1. 「信頼度の段階的上昇」はパチンコ業界の共通アイデアであり、特定メーカーの独占的表現ではない
2. CoinBattleSaki独自の文脈（仮想通貨先物の価格変動）に翻訳している
3. 具体的な映像表現は独自制作する（他機種の映像を模倣しない）

### 3.3 パチンコ演出で注意すべき具体的ライン

| やっていいこと ✅ | やってはいけないこと ❌ |
|---|---|
| 独自デザインの図柄回転演出 | 海物語の「魚群」演出の模倣 |
| オリジナルキャラによるカットイン | 北斗の拳パチンコの「あべし」演出の再現 |
| 独自の信頼度表示システム | 牙狼の「GARO」ロゴ風フォント使用 |
| 画面シェイク・フラッシュ等の汎用エフェクト | 特定機種のBGM・SEの模倣 |
| 「激アツ」「確定」等の一般用語使用 | 「キリン柄」等特定メーカーの信頼度シンボルの模倣 |
| レインボー演出（色の使用は自由） | 特定機種のレインボー演出の構図・動きの模倣 |
| ボタン演出の概念 | 特定機種のボタン演出UIデザインの複製 |

### 3.4 パチンコメーカー各社の演出特許について

パチンコメーカーは演出に関する**特許**を大量に保有している点に注意:

| メーカー | 特許の傾向 |
|---|---|
| SANKYO | 液晶演出のタイミング制御、先読み演出 |
| Sammy | 連動演出、役物と映像の同期 |
| 京楽 | キャラクター演出パターンの制御方法 |
| NEWGIN | 信頼度演出の段階制御方式 |

**ただし**:
- これらの特許は主に「遊技機」（物理的なパチンコ台）に限定された請求項が多い
- スマホゲームアプリは「遊技機」ではないため、直接の特許侵害リスクは低い
- ただし、パチンコメーカーがスマホゲーム向けにも特許を取得している可能性は排除できない

**推奨アクション**:
- [ ] J-PlatPat で主要パチンコメーカーのスマホゲーム関連特許を確認
- [ ] 特に「信頼度演出」「段階的エスカレーション」に関するソフトウェア特許の有無を調査

## 4. 参照作品との類似性分析

### 4.1 ストリートファイターII（カプコン）

| 項目 | 詳細 |
|---|---|
| **参照レベル** | 設計原則の参照（少数精鋭、最小操作×最大表現） |
| **リスクレベル** | 🟢 極低 |
| **理由** | 「設計思想」の参照はアイデアの領域。表現（キャラデザ、画面構成、技名等）を模倣しなければ問題なし |

**注意点**:
- 「リュウ→ケン→豪鬼」のような師弟関係構造は**アイデア**（自由に使える）
- キャラクターの見た目・技のモーション・ステージデザインは**表現**（模倣NG）
- 「波動拳」等の技名は商標登録されている可能性あり → 使用しない

### 4.2 ウマ娘 プリティーダービー（Cygames）

| 項目 | 詳細 |
|---|---|
| **参照レベル** | コンセプトの参照（実在のものをキャラ化して競わせる） |
| **リスクレベル** | 🟢 低 |
| **類似点** | 実在の存在（競走馬/トレーダー）をキャラクター化、育成・対戦要素 |
| **相違点** | 対象が全く異なる（馬 vs 仮想通貨Bot）、ゲームシステム完全別、美少女化しない |

**判断**: 「実在のXをキャラクター化して競わせる」というコンセプトはアイデアであり、著作権の保護対象外。ウマ娘の具体的なUI・演出・キャラデザインを模倣しない限り問題なし。

### 4.3 北斗の拳・牙狼・ウシジマくん（トーン参照）

| 項目 | 詳細 |
|---|---|
| **参照レベル** | トーン・雰囲気の参照（ダーク×アンダーグラウンド） |
| **リスクレベル** | 🟢 極低（ただし条件あり） |

**注意点**:
- 「ダーク・アンダーグラウンドなトーン」はアイデア → 自由
- 特定のセリフ（「お前はもう死んでいる」等）の使用 → 商標/著作権リスクあり
- 特定のビジュアルスタイル（北斗の拳の劇画調等）の模倣 → リスクあり
- これらの作品名をゲーム内で直接言及する → 避けるべき
- パチンコ版の演出を直接参考にする → 具体的映像の模倣はNG

### 4.4 既存の仮想通貨ゲーム・シミュレーション

| 比較対象 | 類似点 | 相違点 | リスク |
|---|---|---|---|
| **3Commas** | Botによる自動取引 | CoinBattleSakiは仮想資金のみ | 🟢 低（ジャンル違い） |
| **Bybit コピートレード** | 他者の戦略を選ぶ | CoinBattleSakiはゲーム | 🟢 低 |
| **仮想通貨デモトレードアプリ各種** | 仮想資金でトレード体験 | CoinBattleSakiはバトル演出が核 | 🟢 低 |
| **Fantasy Crypto** | 仮想通貨の予測ゲーム | ゲーム性が全く異なる | 🟢 低 |

**判断**: CoinBattleSaki の「仮想資金 × Bot選抜 × パチンコ演出」という組み合わせは独自性が高く、直接的な競合・類似サービスは現時点で確認できない。

## 5. キャラクター・アーキタイプのリスク分析

### 5.1 Bot名称（JOHN, MIKE, SARAH, EMMA, ALEX, YUKI, DELTA, ATR）

| 項目 | 詳細 |
|---|---|
| **リスクレベル** | 🟢 極低 |
| **理由** | いずれも一般的な人名または技術用語（Delta, ATR）であり、商標としての識別力が弱い |

### 5.2 アーキタイプ設計（ADR-0008）

| アーキタイプ | 元ネタリスク | 注意点 |
|---|---|---|
| ストリートハスラー | 🟢 一般的類型 | 特定キャラ（例: カイジ）に寄せない |
| カジノマジシャン | 🟢 一般的類型 | ジョーカー（DC）等に寄せない |
| ウォール街CEO | 🟢 一般的類型 | 実在人物の肖像権に注意 |
| 闇金業者 | ⚠️ 中 | ウシジマくんに類似しないデザイン必須 |
| オイルシーク | 🟢 一般的類型 | 人種差別的表現に注意 |
| 中央銀行家 | 🟢 一般的類型 | 実在人物（黒田、パウエル等）の肖像回避 |
| ゴールドマンデータアサシン | ⚠️ 中 | 「ゴールドマン」は Goldman Sachs の商標に抵触する可能性 |
| 伝説のトレーダー | 🟢 一般的類型 | 実在人物（BNF、CIS等）に寄せない |

**要対応**:
- **「ゴールドマンデータアサシン」→ 名称変更推奨**。Goldman Sachs は商標権を積極的に行使する企業として知られる。「ウォール街のデータアサシン」「ヘッジファンドの暗殺者」等に変更すべき
- 闇金業者キャラ → ウシジマくんの「丑嶋」と視覚的に差別化されたデザインにする
- 実在人物に似せたキャラデザイン → パブリシティ権侵害リスク

## 6. AI生成素材のIP リスク（ADR-0007関連）

### 6.1 AI生成画像の著作権問題

| リスク項目 | 詳細 |
|---|---|
| **AI生成物の著作物性** | 日本では「AIが自律的に生成した部分」には著作権が発生しない可能性が高い（文化庁見解） |
| **学習データの著作権** | AI が学習した既存著作物に類似した画像が生成されるリスク |
| **商用利用** | Midjourney, DALL-E 等のToS で商用利用が許可されているか確認必要 |

### 6.2 具体的リスクと対策

| リスク | 対策 |
|---|---|
| 既存キャラに酷似した画像が生成される | CDS（キャラクターデザインシート）で「NG例」を明示 + 生成後に類似性チェック |
| AI生成物に第三者の著作物が混入 | ピクセルアートへのスタイライズ（ADR-0007の方針通り）で回避 |
| 商用利用制限 | 使用するAIツールのライセンス条項を事前確認 |
| 著作権主張できない | ゲーム全体としての著作物性は認められる。個別素材より「ゲーム全体の表現」で保護 |

**ADR-0007の「ピクセルアート化」方針は、AI生成IPリスクの観点からも極めて有効**。ピクセルアートに変換することで:
1. 元の学習データとの視覚的類似性が大幅に低減される
2. 人間のキュレーション・加工が介在し、著作物性が認められやすくなる
3. 独自のアートスタイルとしてIP保護しやすくなる

## 8. 金融規制・投資推奨リスク（詳細分析）

ADR-0001, ADR-0004 で基本対策済みだが、2025-2026年の金商法改正動向を踏まえ、投資推奨リスクを網羅的に分析する。

### 8.1 CoinBattleSaki のサービス特性整理

まず、CoinBattleSaki が「何をするサービスか」「何をしないサービスか」を明確にする:

| やること | やらないこと |
|---|---|
| BTCsakimono の Bot パフォーマンスデータをキャラクターバトルとして**演出** | 実際の暗号資産取引 |
| Bot のリアルタイムパフォーマンスをエンターテインメントとして**視覚化** | 売買シグナルの配信 |
| キャラクターの勝敗を**観戦**する体験を提供 | ユーザーへの投資判断の助言・推奨 |
| 演出（スキン等）への課金 | トレード結果に連動した課金・報酬 |
| — | ユーザー自身がトレード判断を行う機能 |
| — | Bot 戦略のコピーや実運用への誘導 |

**核心**: ユーザーは「観客」であり「トレーダー」ではない。投資判断に関与する導線が設計上存在しない。

### 8.2 サービス類型比較 — CoinBattleSaki の位置づけ

| 比較軸 | CoinBattleSaki | デモトレード | コピートレード | シグナル配信 | 投資助言業 |
|---|---|---|---|---|---|
| **ユーザーの役割** | 観客（観戦のみ） | トレーダー（仮想） | トレーダー（実資金） | トレーダー（実資金） | 投資家（実資金） |
| **ユーザーの投資判断** | ❌ なし | ⚠️ あり（仮想資金） | ✅ あり（実資金） | ✅ あり（実資金） | ✅ あり（実資金） |
| **実際の暗号資産取引** | ❌ なし | ❌ なし | ✅ あり | ✅ あり | ✅ あり |
| **売買タイミングの指示** | ❌ なし | ❌ なし（自己判断） | ⚠️ 間接的にあり | ✅ あり | ✅ あり |
| **課金とトレード結果の連動** | ❌ なし | ❌ なし | ✅ あり（成功報酬等） | ✅ あり（月額等） | ✅ あり |
| **投資助言業登録の要否** | ❌ 不要 | ❌ 不要 | ⚠️ 要検討 | ✅ 必要 | ✅ 必要 |
| **金商法上の位置づけ** | 規制対象外 | 規制対象外 | 金融サービス仲介 | 投資助言業 | 投資助言業 |

**結論**: CoinBattleSaki は「デモトレードよりもさらにライト」な位置づけ。デモトレードですらユーザーが自ら投資判断を行うが、CoinBattleSaki ではユーザーの投資判断が一切介在しない。

### 8.3 金融商品取引法（金商法）の詳細分析

#### 投資助言業の定義

金商法第2条第8項第11号:
> 当事者の一方が相手方に対して、有価証券の価値等又は金融商品の価値等の分析に基づく投資判断に関し、**助言を行うことを約し**、相手方がそれに対し**報酬を支払うことを約する契約**

投資助言業の構成要件:
1. 有価証券・デリバティブ等の**投資判断**に関する助言であること
2. 顧客との間で**助言契約**が存在すること
3. 助言の対価として**報酬**を受け取ること

#### CoinBattleSaki が該当しない理由

| 構成要件 | CoinBattleSaki の状況 | 判定 |
|---|---|---|
| 投資判断に関する助言 | Bot のリアルタイムパフォーマンスをキャラクターバトルとして演出するのみ。「この Bot を使え」「この戦略で取引しろ」という助言は一切行わない | ❌ 該当しない |
| 助言契約の存在 | サービス利用規約は「エンターテインメント提供」であり「投資助言」ではない | ❌ 該当しない |
| 助言対価としての報酬 | 課金対象はスキン等の演出要素のみ。トレード結果や Bot 選択への対価ではない | ❌ 該当しない |
| ユーザーの投資行動への導線 | BTCsakimono への誘導や実取引への導線を設けない | ❌ 該当しない |

**3要件いずれも満たさないため、投資助言業には該当しない。**

| 暗号資産を「金融商品」に分類（2025年5月施行） | CoinBattleSaki は暗号資産の取引・管理を行わないため**直接的影響なし** |

**結論**: 2025-2026年の規制強化は主に「暗号資産の取引・管理・助言を行う事業者」を対象としており、「リアルタイムデータをエンターテインメントとして演出するのみ」の CoinBattleSaki には直接的な影響がない。

### 8.4 「デモトレードよりライト」である根拠の詳細

```
投資助言業（最も重い）
  ↓ 実資金 × 助言契約 × 対価
コピートレード
  ↓ 実資金 × 戦略追従
シグナル配信
  ↓ 実資金 × 売買指示
デモトレード
  ↓ 仮想資金 × ユーザー自身の投資判断
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
CoinBattleSaki ← ここ
  ↓ リアルタイムデータ × 投資判断なし × 観戦のみ
スポーツ中継（参考）
  ↓ 実データ × 観戦のみ
```

CoinBattleSaki はリアルタイムデータを使用するが、性質としては「スポーツ中継」に近い。競馬中継を見ても視聴者が騎手になるわけではないのと同様、Bot のリアルタイムバトルを見てもユーザーがトレーダーになるわけではない。

CoinBattleSaki がデモトレードよりライトである決定的な違い:

1. **ユーザーの投資判断が存在しない**: デモトレードではユーザーが「いつ買う」「いつ売る」を判断する。CoinBattleSaki ではユーザーは Bot の結果をバトルとして**見る**だけ
2. **投資スキルの向上を目的としない**: デモトレードは「投資の練習」が目的。CoinBattleSaki は「キャラクターバトルの観戦」が目的
3. **ポジション選択・資金管理が存在しない**: ロット数、レバレッジ、損切りなどの投資判断要素がゼロ
4. **トレード結果と経済的インセンティブの分離**: どの Bot が勝っても、ユーザーの課金額や報酬に影響しない

#### 設計レベルのセーフガード原則

1. **Bot 成績と投資判断を結びつけない設計**: Bot の勝敗はあくまで「キャラクターの強さ」として表現し、「投資リターン」として表現しない

3. **課金とトレード結果の完全分離**: どの Bot が勝っても課金体験に差が出ない
4. **ランキング表示での注意喚起**: Bot 成績順位の表示時に必ず免責事項を併記
5. **PnL（損益）の直接表示を避ける**: 「+15.3%」のような投資リターン表記ではなく、「HP 残量」「バトルスコア」等のゲーム指標に変換して表示

## 11. 結論と推奨アクション

### パチンコ演出について（最重要回答）

**パチンコ的演出はパクリにならない。** 理由:

1. リーチ・信頼度・確変・予告演出等の「仕組み」はアイデアであり著作権保護の対象外
2. パチンコ業界自体が全メーカー共通の演出文法を使っており、特定メーカーの独占的表現ではない
3. CoinBattleSaki は独自の文脈（仮想通貨Bot）に翻訳するため、具体的な映像表現は完全オリジナル
4. スマホアプリはパチンコ遊技機の特許の請求範囲外である可能性が高い

**ただし「表現」の模倣は別問題**:
- 特定機種の映像・SE・カットインを模倣 → NG
- 「海物語の魚群」「北斗の拳のあべし」等の象徴的演出の再現 → NG
- 独自デザインで同じ「仕組み」を使う → OK

### 大幅な軌道修正は不要

現在の設計は全体としてIP侵害リスクが低い。必要なのは以下の**小規模な修正のみ**:

### 即座に対応すべき項目（高優先度）

1. **「ゴールドマンデータアサシン」の名称変更**
   - Goldman Sachs の商標権に抵触するリスク
   - 提案: 「ヘッジファンドの暗殺者」「クオンツアサシン」「アルゴリズムの死神」等

2. **Binance API ToS の確認**
   - 商用ゲームアプリでの利用可否を確認
   - 代替API（複数取引所対応）の設計を前倒し

### 中期的に対応すべき項目

3. **J-PlatPat での商標調査**
   - 「CoinBattleSaki」「コインバトルサキ」での商標登録可否
   - 第9類（ゲームソフト）・第41類（ゲーム提供）での既存商標確認

4. **キャラクターデザイン時のNG例リスト作成**
   - 各アーキタイプが「寄せてはいけない」既存キャラクターの具体例をCDSに追加
   - 特に: カイジ（ギャンブル漫画）、ウシジマ（闇金漫画）、実在トレーダー
