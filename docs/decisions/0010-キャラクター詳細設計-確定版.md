# ADR-0010: キャラクター詳細設計 — 確定版（提案Bベース）

## ステータス: 確定

## コンテキスト

ADR-0008で「トレーダー × 神獣」の翻訳媒介と8体のキャラクター初期案を設計。
ADR-0009で現行ロスターの問題点を分析し、3つの改善提案（A/B/C）を比較検討。

**提案B（ウマ娘/原神ハイブリッド型 — 推し力最大化）を採用。**

さらに神獣の演出方針として「ナルトの尾獣メカニクス」を導入:
普段は手のひらサイズの可愛いマスコット → 市場が激動するほど巨大化 → 臨界時は画面を埋め尽くす。

本ADRは8キャラの確定版詳細プロフィール + 神獣サイズ成長システムを定義する。

## Part 2: 神獣サイズ成長システム（尾獣メカニクス）

### コンセプト

> ナルトの尾獣が普段は封印状態 → チャクラ開放で段階的に巨大化するように、
> 神獣は普段「ちびマスコット」としてトレーダーの肩に乗っている。
> 市場が動くほど神獣が成長し、臨界時には画面を支配する巨大な存在になる。

### ADR-0007の8段階演出と連動するサイズテーブル

| State | 神獣サイズ | 視覚表現 | トレーダーとの関係 |
|-------|----------|---------|-----------------|
| **S1 凪** | 手のひら（10-15cm） | ちびキャラ。丸い目。モフモフ/ぷにぷに。眠そう | 肩や頭の上に乗っている。たまに欠伸 |
| **S2 気配** | 猫サイズ（30cm） | 目を開く。耳/角/尾が微かに発光。警戒の仕草 | 足元に降りて周囲を見回す |
| **S3 胎動** | 中型犬サイズ（60cm） | 完全実体化。体が発光。戦闘態勢。テーマカラーのオーラ | トレーダーの横に並ぶ。「来るぞ」 |
| **S4 激突** | 人間サイズ（1.5m） | トレーダーと同等。攻撃を放ち始める。ディテールが増す | 並んで戦う。共闘構図 |
| **S5 激アツ** | 大型（3m） | トレーダーより大きい。攻撃の主体が神獣に移行。金のオーラ | トレーダーが神獣を指揮する構図 |
| **S6 覚醒** | 巨大（5-8m） | 画面の半分を占める。上位形態に覚醒。ディテール最大 | **トレーダーが神獣の上に乗る**（騎乗） |
| **S7 臨界** | 超巨大（画面全体） | 画面を埋め尽くす。必殺技。エフェクト爆発 | **トレーダーと完全融合**。一体化して最終攻撃 |
| **S8 尻すぼみ** | 急縮小（→手のひら） | ぷしゅーっと風船が萎むように縮む。コミカルSE | ちびに戻って「ぴぎゃっ」。トレーダーが肩をすくめる |

### 設計根拠

1. **マスコット機能**: S1（全時間の60-70%）で表示されるちび神獣が愛着の核。「自分の神獣」への所有感
2. **直感的スケール**: 神獣のサイズだけで「今どれくらい凄いことが起きているか」が一目で分かる
3. **SNS映え**: 共有カードに表示される神獣サイズが「勝ちの大きさ」の自慢材料になる
4. **S8のコメディ**: 巨大→ちびの急縮小がフラストレーションを笑いに変換
5. **課金ドライバー**: ちびフォーム/巨大フォーム両方にスキンが欲しくなる（「ちび猛隼」等）

### ナルト尾獣との構造的対応

| ナルト | CoinBattleSaki |
|--------|---------------|
| 人柱力（じんちゅうりき） | トレーダー |
| 尾獣 | 神獣 |
| チャクラ = 感情の力 | σ（ボラティリティ）= 市場の力 |
| 尾の本数 = 力の段階 | 神獣のサイズ = 市場の激しさの段階 |
| 尾獣玉（最終技） | S7臨界の必殺技 |
| 暴走（制御不能） | S8尻すぼみ（フェイクアウト） |

| 項目 | 内容 |

| **性別・年齢** | 男・20代前半 |
| **魅力軸** | クール美青年。主人公。ゲームの顔 |
| **体型** | 俊敏な細マッチョ。侍×現代ストリート |
| **カラー** | 青 🔵 |

#### 神獣: 隼（はやぶさ）

| フォーム | 描写 |
|---------|------|
| **ちび（S1）** | 手のひらサイズのモフモフの隼の雛。大きなまん丸の目。迅の肩に乗って居眠り。時々「ピィ」と鳴く |
| **最大（S7）** | 金属羽の超巨大隼。翼で空を切り裂く。音速の急降下。衝撃波が画面を震わせる |

#### 戦略 → バトルスタイル

| 戦略要素 | バトル翻訳 |
|---------|----------|
| 5分足スキャルピング | 超高速の連続攻撃。手数で圧倒 |
| 順張り | 勢いに乗る。相手の攻撃の「流れ」に乗って加速 |
| VWAP接触 / 短期ブレイク | 「隙」を見つけた瞬間に切り込む |
| 小利幅 × 高頻度 | 一撃は浅いが止まらない。百裂斬 |

#### 性格と矛盾

> **表**: 一瞬の判断に全てを賭ける侍気質。寡黙だが行動は最速。「考えるより先に体が動く」
>
> **裏**: スキャルピングの連敗で何度も破産している。**速さは恐怖の裏返し**。止まると負けを直視してしまうから、走り続けるしかない。

#### 必殺技

| 技名 | 演出 |
|------|------|
| **Rapid Slash（瞬速斬）** | 隼が音速で急降下。画面に無数の斬撃線。利確の嵐 |
| **Flash Cut（瞬間撤退）** | 形勢不利時、隼の羽が画面を覆い、一瞬で離脱。損切りの美学 |

#### S8（尻すぼみ）リアクション

> ちび隼が急降下しようとして地面に激突。「ぴぎゃっ！」。迅が無言で拾い上げて肩に戻す。
