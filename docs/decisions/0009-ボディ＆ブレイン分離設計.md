# ADR-0009: ボディ＆ブレイン分離設計

## ステータス: 承認

## コンテキスト

ADR-0005で「8マザーBot × 5バリアント = 48体」、ADR-0008で「金の世界のアーキタイプ蒸留方式」
「エース1体制」「段階的昇格型」が確定した。

しかし、現状の設計には構造的な問題がある：

1. **戦略空間 >> 8**: 仮想通貨先物にはグリッド、DCA、裁定、ファンディングレート等、
   8を大きく超える有効な戦略が存在する
2. **1:1密結合**: 1 bot = 1 character = 1 strategy → 新戦略追加 = 新キャラ制作（高コスト）
3. **技術プロパティでキャラ定義**: 「JOHN = 5m順張り」は人間味がなく、翻訳媒介（ADR-0008）の
   「金の世界のアーキタイプ」と整合しない
4. **48体は管理不能**: 全派生に独立キャラ待遇を与えるのは個人開発で非現実的

### 解くべき問い

> キャラクター数を抑えながら、戦略的多様性を最大化し、
> かつ長期的に拡張可能な設計はどうあるべきか？

---

## 決定: ボディ＆ブレイン分離アーキテクチャ

### 核心的洞察

**SF2のリュウは「波動拳を撃つ人」ではなく「求道者」**。
波動拳は後から真空波動拳、灼熱波動拳と追加されたが、リュウの哲学は変わらない。

同様に、CoinBattleSakiのキャラクターは「5m順張り戦略を使う人」ではなく
**「金に対する哲学を持つ人」**として定義すべきである。

- **ボディ（Body）= 哲学** → 金に対するスタンス。変わらない
- **ブレイン（Brain）= 技** → 具体的な取引戦略。追加・変更可能

### アーキテクチャ

```
ボディ（Body）= キャラクター（8体、固定資産）
  ├─ 金に対する哲学/リスク態度で定義
  ├─ ビジュアル・演出資産を持つ
  └─ 「適性レンジ」が決まっている（装着可能なブレインの範囲）
         ↓
ブレイン（Brain）= トレーディング戦略（コードモジュール、拡張可能）
  ├─ 具体的な売買ロジック（RSI逆張り、MACD順張り、グリッド等）
  ├─ コードのみ（アート資産不要）
  └─ パラメータバリアント（攻撃的/保守的等。旧_agg/_conに相当）
```

### 8体のボディ：金に対する8つの哲学

「時間軸×戦略タイプ」ではなく、**「金に対するスタンス」**で8体を再定義する。

| # | 哲学コード | リスク態度 | 適性ブレインの方向性 | アーキタイプ（ADR-0008） |
|---|-----------|-----------|-------------------|----------------------|
| 1 | **疾風** | 超攻撃・瞬間勝負 | 高速スキャル、ブレイクアウト、高速裁定 | ストリートハスラー |
| 2 | **読み** | 観察→精密な一撃 | 逆張り、ミーンリバージョン、ボリンジャー | カジノの魔術師 |
| 3 | **支配** | 圧倒的優位を築く | 中期トレンドフォロー、モメンタム、MACD | ウォール街の女帝 |
| 4 | **回収** | 確実に搾り取る | グリッド、DCA、ファンディングレート裁定 | 闇金の回収者 |
| 5 | **泰然** | 巨大資金×低リスク | 長期トレンドフォロー、長期スイング | 石油王 |
| 6 | **沈黙** | 滅多に動かない→動いたら圧倒 | 長期逆張り、ATR急拡大逆張り | 中銀砲 |
| 7 | **暗算** | データで殺す | デルタ確認、統計的裁定、マルチタイムフレーム | データの暗殺者 |
| 8 | **待機** | 嵐の時だけ出る | ボラティリティ戦略、清算カスケード狙い | 嵐を待つ者 |

**SF2原則3（根本的差別化）の検証：**
- 疾風 vs 沈黙 = 速度が正反対
- 支配 vs 読み = 攻め vs カウンター
- 回収 vs 待機 = 常時稼働 vs イベント特化
- 泰然 vs 暗算 = 直感 vs データ
- 8体全てが根本的に異なるプレイ体験を提供する ✅

### ブレインカタログ（拡張可能）

| カテゴリ | ブレイン名 | 適性ボディ | 実装フェーズ |
|---------|-----------|----------|------------|
| トレンドフォロー | MACD順張り | 疾風、支配、泰然 | MVP |
| トレンドフォロー | SMAクロス | 支配、泰然 | MVP |
| ミーンリバージョン | RSI逆張り | 読み、沈黙 | MVP |
| ミーンリバージョン | ボリンジャー回帰 | 読み、回収 | MVP |
| ブレイクアウト | レンジブレイク | 疾風、待機 | MVP |
| デルタ確認 | OI+価格乖離 | 暗算 | MVP |
| ATR逆張り | ATR急拡大リバーサル | 沈黙、待機 | MVP |
| レンジ蓄積 | グリッド | 回収 | MVP |
| グリッド | レンジグリッド | 回収 | v1.x |
| DCA | 定期積立 | 回収、泰然 | v1.x |
| ファンディングレート | FR裁定 | 暗算、回収 | v1.x |
| マルチタイムフレーム | 階層分析 | 暗算、支配 | v2.x |
| ボラティリティ | 清算カスケード狙い | 待機 | v2.x |

MVPでは各ボディに最低1つのデフォルトブレインを保証する。

### 適性レンジ（互換性ルール）

各ボディは「哲学」に適合するブレインのみ装着可能：

- **疾風**: 高速系（5m、ブレイクアウト、高速裁定）
- **読み**: カウンター系（逆張り、ボリンジャー、精密エントリー）
- **支配**: 中期攻勢系（15mトレンドフォロー、モメンタム、MACD）
- **回収**: 蓄積系（グリッド、DCA、FR裁定）
- **泰然**: 長期安定系（1hトレンドフォロー、長期スイング）
- **沈黙**: 長期逆張り系（1h逆張り、ATR急拡大）
- **暗算**: データ系（デルタ、統計的裁定、マルチTF）
- **待機**: イベント系（ボラティリティ戦略、清算カスケード）

一部のブレインは複数ボディに適性あり（例: MACD順張りは疾風・支配・泰然で使える）。
ただし同じブレインでもボディによって戦い方の「味」が変わる
（疾風のMACDは超高速判断、泰然のMACDは悠然とした大きなトレンド狙い）。

### パラメータバリアント

各ブレイン内で以下のパラメータ軸を調整可能：

| 軸 | 低 | 高 | 旧バリアントとの対応 |
|---|----|----|--------------------|
| 攻撃性 | 低レバ・小ポジション | 高レバ・大ポジション | _con ↔ _agg |
| 速度 | 長い確認期間 | 即座のエントリー | _slow ↔ _fast |
| リスク | 広いストップロス | 狭いストップロス（高リスク） | — ↔ _risk |

**重要**: パラメータバリアントは**キャラの見た目を変えない**。
同じボディ、同じブレイン、パラメータだけが違う。
プレイヤーには「攻撃的モード / 慎重モード」のような切り替えとして見せる。

### プレイヤー体験（段階的開放）

**初心者モード**（デフォルト）:
```
ボディ選抜 → 通貨ペア → レバレッジ → 資金投入額
（ブレインはデフォルトが自動選択。パラメータも標準）
```

**上級者モード**（アンロック後）:
```
ボディ選抜 → ブレイン選択 → パラメータ調整 → 通貨ペア → レバレッジ → 資金投入額
```

初心者は「キャラを選ぶだけ」で遊べる。
上級者は「キャラ×ブレイン×パラメータ×市場」の深い戦略空間にアクセスできる。
SF2原則2「最小操作×最大表現」を段階的に体現。

## 理由

### なぜボディとブレインを分離するか

1. **アート工数の固定化**: 8体のビジュアル制作で済む。新戦略はコードのみ
2. **戦略の無限拡張**: ブレインはコードモジュール。追加コストがほぼゼロ
3. **キャラの永続性**: 「疾風」の哲学は30年変わらない。技（ブレイン）は自由に追加可能
4. **プラガブル設計**: ADR-0005の「Bot戦略のプラガブル設計」要件を自然に満たす
5. **コンテンツ更新**: 新ブレイン追加 = 新シーズンのコンテンツ（キャラ制作不要）

### なぜ8体で十分か

1. **SF2が証明済み**: 8体の根本的差別化は30年以上機能し続けている
2. **戦略の多様性はブレインが担う**: キャラ数 ≠ 戦略数。8体でも組み合わせは80以上
3. **個人開発の現実**: 8体のフル演出資産制作が実質的な上限
4. **IP構築**: 少数精鋭の方がキャラクターへの愛着が生まれやすい

### コスト分析

| 拡張フェーズ | アート工数 | コード工数 | 合計ボディ | 合計ブレイン | 組み合わせ数 |
|------------|----------|----------|----------|------------|------------|
| MVP | 8体 | 8戦略 | 8 | 8 | ~16-24 |
| v1.x | 0 | +4戦略 | 8 | 12 | ~30-40 |
| v2.x | +2体（昇格） | +4戦略 | 10 | 16 | ~50-60 |
| v3.x | +2体（シーズン） | +4戦略 | 12 | 20 | ~70-80 |

**旧モデル（1:1密結合）**: 80組み合わせ = 80体のキャラ制作（非現実的）
**新モデル（分離）**: 80組み合わせ = 12体 + 20コードモジュール（現実的）

## リスク

| リスク | 影響 | 対策 |
|--------|------|------|
| ブレイン選択が複雑すぎる | 初心者が離脱 | 段階的開放。初心者はキャラ選ぶだけ |
| 同じボディに違うブレインだと個性が薄れる | キャラの一貫性が崩れる | 適性レンジで「哲学に合わないブレイン」を排除 |
| ブレイン間のバランスが取れない | 最強ブレインにみんなが集中 | 市場状況で有利不利が変わる設計。常に最強は存在しない |
| 適性レンジが窮屈すぎる | 組み合わせの楽しさが減る | 各ボディに最低2-3ブレイン。一部は複数ボディに対応 |

---

## 代替案

### A. 完全自由型（どのボディにもどのブレインも装着可能）
最大の自由度だが、キャラの個性が失われる。
ザンギエフが波動拳を撃てたらSF2は壊れる。却下。

### B. 完全固定型（1ボディ = 1ブレイン、変更不可）
現状のADR-0005方式。シンプルだが拡張性がない。
新戦略 = 新キャラ必須でコストがスケールしない。却下。

### C. ブレインを隠す（プレイヤーにはキャラだけ見せる）
内部的にはボディ＆ブレインだが、プレイヤーからは見えない。
シンプルだが「組み合わせを探す楽しさ」がなくなる。
段階的開放方式で初心者には隠し、上級者には見せることで解決。部分採用。

## ADR-0005「48体」との関係

本ADRにより、ADR-0005の「8マザー×5バリアント=48体」は以下のように再解釈される：

- **8マザー → 8ボディ**: 哲学ベースで再定義（技術プロパティベースから変更）
- **5バリアント → パラメータバリアント**: ボディの見た目は変わらない。同じブレイン内のパラメータ調整
- **48体 → 不要**: 48の独立キャラは必要ない。8ボディ × N ブレイン × パラメータで多様性を担保

ADR-0005のBot engine移植対象（トレード判定ロジック、Binance API、localStorage等）は
そのまま有効。ブレインのコードモジュールとして再構成するだけ。
