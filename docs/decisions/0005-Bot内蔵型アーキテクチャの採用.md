# ADR-0005: Bot内蔵型アーキテクチャの採用

## ステータス: 承認

## コンテキスト

当初の設計では、BTCsakimono（既存サービス）からAPIでBot戦績データを取得し、
CoinBattleSakiは「演出のみ」を担当する分離型アーキテクチャを想定していた。

しかし、BTCsakimonoの調査結果から以下が判明:
- BTCsakimonoは `index.html` 1ファイル（約7,000行）の完全クライアントサイドSPA
- すべてのデータはブラウザのlocalStorageに保存
- サーバーサイドAPI・静的JSONファイル・DBは一切存在しない
- 外部からのデータ取得は現状不可能
- 開発者は4時間でBot50体システムを構築した実績がある

連携のためにBTCsakimonoにエクスポート機能を追加する方法もあるが、
Bot engine自体が軽量（個人+AIで半日レベル）であることを踏まえ、
CoinBattleSakiにBot engineを内蔵する方が合理的と判断。

## 決定: Bot内蔵型アーキテクチャを採用

### 旧アーキテクチャ（却下）
```
BTCsakimono（既存） → API → CoinBattleSaki（演出のみ）
```

### 新アーキテクチャ（採用）
```
CoinBattleSaki = Bot engine + 8状態変換 + エンタメ演出（全部入り）
```

### 構成
```
┌─────────────────────────────────────────────┐
│            CoinBattleSaki（クライアントサイド）  │
│                                               │
│  ┌──────────┐  ┌──────────┐  ┌────────────┐  │
│  │ Bot Engine│→│ 8状態変換 │→│ エンタメ演出 │  │
│  │ (市場データ│  │  レイヤー │  │  レイヤー  │  │
│  │  取得+判定)│  │          │  │ (IP/キャラ) │  │
│  └──────────┘  └──────────┘  └────────────┘  │
│       ↑                           ↓          │
│  Binance API              localStorage       │
│  (REST ポーリング)          (戦績保存)         │
└─────────────────────────────────────────────┘
```

### BTCsakimonoからの移植対象

| 要素 | 移植方針 | 備考 |
|------|---------|------|
| BOT_DEFS (8マザー+チャイルド) | 構造を参考に再設計 | SF2原則に基づきキャラとして再定義 |
| トレード判定ロジック | ほぼそのまま移植可能 | RSI/MACD/SMA等のテクニカル計算 |
| Binance API呼び出し | そのまま移植 | REST APIポーリング |
| localStorage保存 | そのまま移植 | trades[], botStates等 |
| UI/ダッシュボード | 完全に作り直し | エンタメ演出に置き換え |

### メリット
1. **サーバーゼロが完全に実現**: API連携不要、全処理がクライアントサイド
2. **外部依存ゼロ**: BTCsakimonoの変更・停止に影響されない
3. **開発速度**: Bot engineは4時間で構築可能（実績あり）
4. **一体化**: Bot行動→8状態変換→演出の全パイプラインを最適化可能
5. **App Store配布が容易**: 自己完結型アプリとして申請可能

### デメリット・リスク
1. **Binance API依存**: Binanceが止まるとBot engineが動かない
   → 対策: 複数取引所対応（将来）、オフラインリプレイモード
2. **ブラウザ稼働中のみ動作**: ブラウザ/アプリを閉じるとBotが停止
   → 対策: App版ではバックグラウンド実行、Web版では「閉じてた間」を巻き戻し再計算
3. **localStorage消去で全データ消失**
   → 対策: エクスポート/インポート機能、将来的にiCloud/Google Drive同期

### データフィールド（移植対象）
- trades[]: time, dir, entry, exit, size, lev, pnlPct, pnlAbs, compositeScore, note
- botStates: id, position, trades[], dailyStats[], totalWins, totalLosses, totalPnlPct, params, pdcaLog[]
- position: null | {dir: 'LONG'|'SHORT', entry, ...}（部分決済なし、全決済のみ）

## 代替案
- BTCsakimonoにJSON出力機能を追加して連携 → 開発・運用コストが分散するため却下
- BTCsakimonoのコードをサブモジュールとして取り込む → 7000行の単一HTMLは分割困難
- サーバーサイドでBot実行 → サーバーゼロ原則に反するため却下
