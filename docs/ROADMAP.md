## 技術アプローチの提案：Web MVP → Unity製品化

### なぜ「Web先行」を推奨するか

| 観点 | Web先行 | Unity一本 |
|------|---------|----------|
| **今すぐ始められる** | ✅ 環境構築不要 | ❌ Unity DL+学習が先 |
| **ビジュアル確認** | ✅ ブラウザで即確認 | △ ビルド待ち時間あり |
| **Claude との相性** | ✅ HTML/CSS/JSを直接書ける | △ Unityはエディタ操作が必要 |
| **既存資産** | ✅ プロトタイプが既にある | × ゼロから |
| **最終的なUnity移植** | ロジック・演出設計をそのまま移植可能 | — |

**結論**: Web版をフル機能MVPとして完成させ、それを「設計書兼動作仕様書」としてUnityに移植する。

**Web MVPは「捨てる試作」ではない**:
- PWA化すればスマホアプリとして配布可能（App Store不要）
- ビジュアルクオリティはCSS + Canvas + WebGLで十分到達可能
- BTCsakimonoが元々7,000行のHTML = Web技術で作られている

