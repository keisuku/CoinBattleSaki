# バトルシステム設計 Skill

## Description
市場データをバトルに変換するゲームメカニクスの設計ガイド。

## Instructions

### 市場データ→バトルアクション変換ルール

#### 基本メカニクス
```
市場データの変動 → Bot戦略の判断 → バトルアクション → ゲーム演出
```

#### 変換テーブル（基本）
| 市場イベント | バトルアクション |
|-------------|----------------|
| 価格上昇（小） | ジャブ・軽パンチ |
| 価格上昇（大） | 強攻撃・ラッシュ |
| 価格下落（小） | ガード・ステップバック |
| 価格下落（大） | ダメージ・ダウン |
| 急騰（+5%以上） | 必殺技発動 |
| 急落（-5%以上） | 超必殺技 or 大ダメージ |
| レンジ相場 | 牽制・フットワーク |
| 出来高急増 | バフ・パワーアップ |
| ボラティリティ上昇 | ラウンド加速 |

#### バトルの勝敗判定
- **HP**: Botのポートフォリオ価値に連動
- **ラウンド制**: 一定時間区切りで判定（例: 5分×3ラウンド）
- **判定基準**: 収益率（PnL）、シャープレシオ、最大ドローダウン
- **KO条件**: 一方のBotが大きな含み損（例: -20%以上）

#### 演出ガイドライン
- 市場が穏やかな時: キャラクター同士の牽制、間合いの取り合い
- 市場が動き始めた時: 攻撃が増える、テンポが上がる
- 急変動時: 必殺技・超必殺技の演出、画面エフェクト
- 決着時: リプレイ演出、戦績表示

### 注意事項
- **投資助言にならない表現**: 「このBotが勝った=この戦略が儲かる」と
  受け取られないよう、あくまでエンターテイメントとしての演出を心がける
- **免責事項の表示**: シミュレーション結果は将来の収益を保証しない旨を明記
- **過去データでの検証**: バックテストモードで演出のバランスを調整可能にする
