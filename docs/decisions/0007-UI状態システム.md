# ADR-0007: UI状態システム — 「演出侵食型」プレゼンテーション

## ステータス: 承認

## コンテキスト

CoinBattleSakiの画面設計において、AI生成モックアップによるプロトタイピングの結果、
**通常時（チャートのみ）が「トレーディングアプリ」に見え、「ゲーム」に見えない**という
致命的な問題が判明した。

### ユーザーフィードバック（原文）
> 「通常時にチャートだけ過ぎるのは少しチャート寄り過ぎて微妙かもしれません。
> botが常に予兆を感じてるような、トレーダーがテクニカル指標を感じ取るように、
> botが気配を感じ取ったり、そろそろエントリーするのかな！？どうなのかな？
> といった形や、エントリー、利確・損失ラインを予め見せておいて、
> そこに到達するのかな！？どうなのかな！？という感じにしたいです。」

### 本質的な問題
チャートは「データ表示ツール」であり、それだけではゲーム体験にならない。
プレイヤーは常に以下を知りたい:
- **「Botは今何を考えているのか？」**
- **「次に何が起こり得るのか？」**

これは既存のゲームが全て解決済みの問題であり、学ぶべきパターンがある。

### 参考ゲーム分析

| ゲーム | 常に画面にあるもの | 「次に何が起こるか」の可視化 | CoinBattleSakiへの翻訳 |
|--------|-------------------|---------------------------|----------------------|
| パズドラ | 味方パーティ | スキルゲージが溜まっていく | Botのインジケーターバーが「溜まる」 |
| ウマ娘 | 馬（キャラ）の姿 | ゴールまでの距離 | TP/SLまでの距離 |
| パチンコ | 盤面の玉 | 玉がポケットに近づく/離れる | 価格がラインに近づく/離れる |
| FGO | サーヴァント | NPゲージの充填 | コンポジットスコアの充填 |

**共通パターン**: キャラクターが常に見え、「何かが溜まっている/近づいている」ことが可視化されている。
これを「**演出侵食型（Presentation Invasion）**」と名付ける。

---

## 決定: コンポジットスコア駆動の5状態演出侵食システム

### 基本原則

```
チャートがメインでBotはおまけ ← ❌ トレーディングアプリ
Botが主役でチャートはBotの戦場 ← ✅ ゲーム
```

画面にBotが常に存在し、Botの「思考」と「意図」がチャート上に可視化される。
演出の強度は市場状況に応じて段階的に変化し、激しい場面ではチャート領域を
演出が「侵食」していく。

---

## 1. 画面レイアウト: 常に存在する要素

Botパネルとチャートが同時に表示される固定レイアウト。
Botパネルは**決して消えない**（パズドラの味方パーティと同じ）。

### 画面比率（状態により変動）

| 状態 | チャート | Botパネル | 演出オーバーレイ |
|------|---------|----------|----------------|
| State 1: 待機 | 55% | 25% | 0% |
| State 2: 予兆 | 50% | 30% | 0% |
| State 3: アクション | 40%→50% | 30% | 一時的30%(カットイン) |
| State 4: 激アツ | 45% | 30% | 端5%（グロー） |
| State 5: 決着 | 30% | 40% | 30%（オーバーレイ） |

**ポイント**: 状態が激しくなるほど演出がチャート領域を「侵食」するが、チャートは完全には消えない。

## 2. コンポジットスコア — ドラマエンジン

### 概要

Botのエントリーロジックの各条件の充足度を0-100%の連続値で表現する。
パズドラのスキルゲージ充填と同じ構造だが、**上がったり下がったりする**のが
パチンコの玉がポケットに近づいたり離れたりするドラマと一致する。

### 算出方法

各Botのエントリー条件を重み付きで合算:

```
例: SARAH（15m順張り）のエントリー条件:
  - RSI(14) > 55                    → 25%の重み
  - MACDヒストグラム > 0 かつ上昇中   → 25%の重み
  - 価格 > SMA(50)                  → 25%の重み
  - 出来高 > 平均の1.2倍             → 25%の重み

RSIが52の場合（閾値55に対して）:
  RSI貢献 = 25% × (52/55) = 23.6%

全条件の重み付き合計 = コンポジットスコア
100%到達 = 全条件充足 → エントリー発動
```

コンポジットスコアは連続値であり、ステップ関数ではない。
これにより、感情遷移が滑らかになる。

### 視覚表現

```
コンポジットスコア（エントリー条件充足度）:

0%                    50%              80%     100%
|░░░░░░░░░░░░░░░░░░░░|░░░░░░░░░░░░░░░|░░░░░░░|██|
何も起きていない        温まってきた      激アツ!  エントリー!

帯域ごとの視覚処理:
  0-30%:   グレーのバー。Botは穏やか。
  30-60%:  バーが青/緑に変化。Botが身を乗り出す。
  60-80%:  バーが黄/橙に。脈動アニメーション。画面端が薄く光る。
  80-95%:  バーが赤に。高速脈動。Botが武器/ツールを構える。
  95-100%: バーがフラッシュ。全画面の緊張感演出。

重要: コンポジットは「後退」する。
  市場がエントリー条件に近づき、85%に達してから引き戻し、50%に下がる。
  → これが「ああ...惜しかった！」のパチンコ的ドラマ。
```

## 3. ゴーストライン — 予測ライン・システム

### 概要

**エントリー前から、Botが「こうなったら入る」価格ラインをチャート上に半透明で表示する。**
TP/SLの想定位置も併せて表示。これにより、通常時でも
「あのラインに到達するのかな？しないのかな？」というドキドキ感が常にある。

### ラインの種類と視覚処理

```
ラインの種類    色              スタイル           透明度       ラベル
──────────────────────────────────────────────────────────────────────
ゴーストEntry  #FFD700(金)     破線             20-80%       "$97,800 ⚔ SARAHのエントリー"
                              composite連動     composite    + 距離 "あと$366"
                                               に比例

TP（利確）     #FFD700(金)     実線, 2px        100%         "$98,500 ✦ TP +0.71%"
              星モチーフ       脈動（近接時）    エントリー後   + 距離 "あと$550"

SL（損切）     #FF2222(赤)     実線, 2px        100%         "$97,200 ☠ SL -0.62%"
              警告モチーフ     脈動（近接時）    エントリー後   + 距離 "あと$610"

Entry（参照）  #AAAAAA(灰)     実線, 1px        100%         "$97,810 ⚔ Entry"
                              エントリー後は                  基準線として表示
                              参照線になる
```

### ゴーストラインの振る舞い

```
エントリー前のゴーストライン:

1. Botが計算: 「今入るとしたら$Xで入る」
   → $Xに薄い破線ラインを描画

2. Botが計算: 「TPは$Y、SLは$Z」
   → $Y, $Zにさらに薄い点線ラインを描画
   → 市場が変わると位置が移動する

3. コンポジットスコアに連動して不透明度が変化:
   → 0% composite: 20%透明（うっすら見える）
   → 50% composite: 50%透明（はっきり見える）
   → 80% composite: 80%透明（ほぼ実線）
   → 100% composite: 完全実線 → エントリー発動

これにより、State 1（待機）でも「退屈なチャート」ではなく
「ラインに近づくかどうか」を見守る画面になる。
```

### 距離表示システム

距離ラベルは緊張感の主要メカニズム。ウマ娘の「先頭との差」と同じ構造。

```
遠い（>50%）:     "あと $550"         小テキスト, 通常色
中間（20-50%）:   "あと $220"         中テキスト, 色が濃くなる
近い（10-20%）:   "あと $120!"        大テキスト, 脈動
非常に近い（5-10%）: "あと $55!!"     特大テキスト, フラッシュ
直前（<5%）:      "あと $12!!!"       最大サイズ, 全画面演出
```

## 4. 5状態システム

### State 1: 待機 — 「Botは生きている」

**条件**: コンポジットスコア 0-30%。強いシグナルなし。全体の60-70%の時間。

**ユーザーのフィードバックにより、「退屈なチャート」ではないことが必須条件。**

```
┌───────────────────────────────────────────┐
│ BTC/USDT  $97,432.50  ▲+0.1%    [15m] ⚙ │
├───────────────────────────────────────────┤
│                                           │
│  ┌───────────────────────────────────┐    │
│  │  $97,800 ┈┈┈┈┈┈┈┈┈┈┈┈ (faint)  │    │  ← Botが算出したエントリー
│  │          ╷                        │    │    薄い破線で表示
│  │      ▓▓▓▒▒░░   ← ローソク足      │    │
│  │      ▓▓▓▒▒░░                     │    │
│  │          ╵                        │    │
│  │  $97,000 ┈┈┈┈┈┈┈┈┈┈┈┈ (faint)  │    │  ← 逆張りのエントリー
│  │                                   │    │
│  │  * レーダースキャンのような        │    │  ← アンビエントエフェクト
│  │    微かなパーティクルが流れる *    │    │
│  │                                   │    │
│  └───────────────────────────────────┘    │
│                                           │
│  ┌────────────┬──────────────────────┐    │
│  │  ╭───╮     │                      │    │
│  │  │ ◉ │     │ "RSIが中立帯...      │    │  ← 思考テキスト
│  │  │ ─ │     │  待機中。"           │    │    10-15秒毎にローテーション
│  │  │   │     │                      │    │
│  │  ╰───╯     │ RSI:  ███████░░░ 48  │    │
│  │  SARAH 🟢  │ MACD: ████░░░░░  -3  │    │
│  │  [calm]    │ Vol:  ██░░░░░░░  低   │    │
│  │            │                      │    │
│  │            │ ◎ Composite: 18%     │    │  ← 低い = 穏やか
│  │            │ ░░░░░░░░░░░░░░░░░░░  │    │
│  └────────────┴──────────────────────┘    │
│                                           │
│  [ノーポジ] [SARAH🟢] [EMMA🔴] [ALEX🟡]  │
└───────────────────────────────────────────┘
```

**Botの振る舞い**:
- アバター: 目がゆっくり左右にスキャン（微細アニメーション）
- 呼吸アニメーション: 静止して見えないための微細な動き
- 思考テキスト（10-15秒毎にローテーション）:
  - 「RSIが中立帯...様子を見る」
  - 「出来高が低い。まだ動きがない」
  - 「MACDがゼロラインに近づいてきた...」
  - 「次の15分足を待つ」
- チャート: 微かな「スキャン」パーティクルが定期的にチャート上を流れる

**重要**: 思考テキストはランダムなフレーバーテキストではない。
Botの実際のインジケーター値を反映する。RSIが48なら「RSIが中立帯」と言う。
これがプレイヤーのインジケーターリテラシーを自然に育てる（GDDの「隠れた教育的価値」）。

**Botの振る舞い**:
- アバター: 目が見開く。体がリラックスから注意に変化。やや前傾。
- 思考テキスト（5-8秒毎、より切迫感）:
  - 「RSIが34まで下がってきた...!」
  - 「もう少しで条件が揃う」
  - 「出来高が増えてきた。何かが起きそう」
- コンポジットバー: グレー → 青/緑に変化。脈動アニメーション開始。
- チャート変化:
  - エントリーラインが60%不透明度に。柔らかいグロー追加
  - **距離ラベル**出現: 「あと$366」がリアルタイム更新
  - 現在価格とエントリーラインの間にグラデーション

**コンポジット後退時の演出**:
- バーが「しぼむ」アニメーション
- Botがやや落胆
- 思考テキスト: 「...離れていったか。まだ待つ」
- これが「玉がポケットから離れた」パチンコドラマ

  - Entry〜TP間に薄い緑の塗り
  - Entry〜SL間に薄い赤の塗り
  - リスク:リワード比を表示

### State 3B: ポジション保持 — 「レースが始まった」

**条件**: エントリー後、Botがポジションを保持中。TP/SLラインが「ゴールライン」。

```
┌───────────────────────────────────────────┐
│ BTC/USDT  $97,950.00  ▲+1.1%    [15m] ⚙ │
├───────────────────────────────────────────┤
│                                           │
```

## 5. Bot感情状態マシン

Botキャラクターは常に明確な感情状態を持つ。アバターアニメーションと思考テキストの内容を駆動する状態マシン。

### 感情状態テーブル

| 感情状態 | トリガー | アバター表情 | ボディランゲージ | 思考テキストのトーン |
|---------|---------|------------|---------------|------------------|
| `calm_scanning` | Composite 0-15% | 半目、無表情 | 腕組み or 体側、呼吸アニメ | 分析的、観察的 |
| `alert_watching` | Composite 15-30% | 目が開く、眉がわずかに上がる | 腕組み解除、姿勢が正される | 変化を記録、軽い好奇心 |
| `interested` | Composite 30-50% | 目が大きく、眉上がる | やや前傾、顎に手 | 興味津々、「何か起きそう」 |
| `tense` | Composite 50-70% | 眉がひそまる、顎が締まる | 武器/ツールに手を伸ばす | 切迫した分析、カウントダウン |
| `ready` | Composite 70-90% | 鋭い凝視、わずかな笑み | 武器構え、戦闘態勢 | 「もう少し」「条件がほぼ揃った」 |
| `locked_in` | Composite 90-100% | 完全集中、決意 | アタック準備ポーズ | 「NOW」的エネルギー、単語の切迫感 |
| `hopeful` | ポジション中、TP方向 | わずかな笑み、明るい目 | TP方向に身を乗り出す | 応援、利益カウント |
| `nervous` | ポジション中、SL方向 | 唇を噛む、汗 | 後退、防御姿勢 | 心配、「持ちこたえろ」 |
| `ecstatic` | TP残り10%以内 | 満面の笑み、キラキラ | 拳を振る、跳ねる | 「もう少し!!」興奮 |
| `desperate` | SL残り10%以内 | 歯を食いしばる、苦悶 | 身構える、盾を構える | 「ダメだ」「耐えろ!!」 |
| `triumphant` | TP到達 | CDS定義の勝利表情 | CDS定義の勝利ポーズ | 祝勝 |
| `defeated` | SL到達 | CDS定義の敗北表情 | CDS定義の敗北ポーズ | 短い絶望、すぐ回復 |

### 感情遷移グラフ

```
calm_scanning → alert_watching → interested → tense → ready → locked_in
                                                                    ↓
                                                                [ENTRY]
                                                                    ↓
                                                hopeful ←→ nervous
                                                   ↓            ↓
                                                ecstatic    desperate
                                                   ↓            ↓
                                                triumphant  defeated
                                                                    ↓
                                                              recovering
                                                                    ↓
                                                              calm_scanning
```

`hopeful ←→ nervous` の双方向遷移が、ポジション保持中のドラマの核心。
価格の揺れに応じてBotが目に見えて希望と不安の間を揺れ動く。

**遷移ルール**: 感情は即座にジャンプしない（エントリー/決着を除く）。
滑らかに補間される。これが「生きている」感覚を生む。

## 7. 状態疲労防止メカニズム

コンポジットが50-60%で長時間横ばいの場合、「予兆」の緊張感にプレイヤーが麻痺する問題への対策。

```
同一10%帯域に3ロウソク足以上留まった場合:
  - 視覚的な強度がわずかに減衰（ただし待機には戻さない）
  - Botの思考: 「この水準で膠着してる...」
  - プレイヤーの緊張感麻痺を防ぐ
  - compositeが再び動き出した場合、即座に強度復帰
```

## 9. Bot種別ごとのドラマ特性

コンポジットスコアの変動速度はBot種別によって異なり、これがゲーム内の「キャラクターの個性」を演出面で表現する。

| Bot | 時間軸 | コンポジット変動 | ドラマ特性 |
|-----|--------|----------------|----------|
| JOHN/MIKE | 5m | 高速。頻繁に上下。 | コンボキャラ。短い緊張の連続。 |
| SARAH/EMMA | 15m | 中速。じわじわ溜まる。 | バランスキャラ。適度な緊張の波。 |
| ALEX/YUKI | 1h | 低速。ゆっくり溜まるが爆発力大。 | パワーキャラ。長い蓄積、稀だが劇的なクライマックス。 |
| DELTA | 15m | デルタ確認依存。特殊な動き。 | テクニカルキャラ。読みにくいがハマると強い。 |
| ATR | 1h | ATR拡大に依存。ボラ急増で急変。 | カウンターキャラ。普段は静かだが荒れると覚醒。 |

これは格ゲーのキャラ多様性と同構造: 手数型 vs 一撃型。

| 1 | Botパネル + コンポジットスコアバー | これだけでチャートが「ゲーム画面」に変わる |
| 2 | ゴーストエントリーライン | 「到達するかな？」の緊張感が常時生まれる |
| 3 | TP/SLライン + 距離ラベル | ポジション保持中のコアドラマ |
| 4 | 思考テキスト（実インジケーター値反映） | 最小アセットコストでBotの「生きてる感」 |
| 5 | State 4 視覚エスカレーション | パチンコ的クライマックス |
| 6 | State 5 勝利/敗北オーバーレイ | ペイオフの瞬間 |
| 7 | Bot感情遷移 | 最初はcalm/alert/excited/resultの4状態で開始 |
| 8 | サウンドデザイン | 視覚システム安定後に追加 |
| 9 | 他Bot認知表示 | Bot切替メカニクス強化 |

## 11. GDDとの整合性

本ADRは以下のGDD/ADRの内容を具体化する:

| 参照元 | 内容 | 本ADRでの解決 |
|--------|------|-------------|
| GDD Section 5 | パチンコ的信頼度エスカレーション | コンポジットスコア → 5状態で完全マッピング |
| GDD Section 10 課題#2 | 信頼度マッピング | Bot indicator → Composite Score → Emotion → Visual State |
| GDD Section 3 | Bot起用判断 | Bot切替バーの他Bot認知表示で実装 |
| ADR-0005 | 8状態変換レイヤー | 5状態 + 12感情状態で具体化 |
| ADR-0006 | CDS poses定義 | 12感情状態分のポーズが必要（CDSテンプレート拡張対象） |

## 12. 代替案

### 案A: チャート全画面 + Botはポップアップのみ
- メリット: チャートが大きく見やすい
- デメリット: 「トレーディングアプリ」にしか見えない。ゲーム感ゼロ
- 判定: **却下（ユーザーフィードバックで明確に否定）**

### 案B: Bot全画面 + チャートは小さなウィジェット
- メリット: キャラ主体で明確にゲーム
- デメリット: 市場データが見づらい。トレーダー層の離脱
- 判定: **却下（チャートも重要な情報）**

### 案C: 本ADRの方針（50:50のハイブリッド + 演出侵食型） ← 採用
- メリット: チャートとキャラの両方が常に見える。状態に応じてバランスが変動
- デメリット: 画面設計が複雑
- 判定: **最適解。「ゲーム」と「市場データ」の両立**

## まとめ: 5つの鉄則

1. **Botは決して消すな** — 画面から消えた瞬間、それは「トレーディングアプリ」になる
2. **何かが常に「溜まっている」** — コンポジットスコアかTP/SL距離か、常に「次」への期待がある
3. **距離を見せろ** — 「あと$550」の数字がリアルタイムで変わることが、最もシンプルで最も強力なドラマ装置
4. **後退もドラマ** — コンポジットが下がる、価格がTPから離れる、この「惜しかった!」がパチンコの核心
5. **Botは考えている** — 思考テキストが実データを反映することで「AI感」と「教育価値」を同時に実現
